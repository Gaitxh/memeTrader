在单机、免费数据源和 Paper 前向约束内，持续优化共享的 `发现 -> 行情采集 -> 计算 -> 策略判断 -> 模拟执行` 主链路；用真实前向结果淘汰负期望策略，并检验更早进入、快/慢退出和分链差异。不得承诺盈利，也不得用未来 ATH 反推入场。

## 冻结边界

- Live 关闭；当前资金期保持 `chain-meme-trader/funding-20260906-v002-final-1000`，不重置历史。
- 买入前必须有新鲜原池且流动性达到有效门槛；已知新鲜原池低于有效门槛时不买。卖出前后同样检查；新鲜证据确认原池低于门槛时剩余仓位核销，缺失/失败/陈旧证据本身不证明全亏。

- 发现、采集和计算是全策略共享底座；策略不得通过专属请求拖慢持仓和待卖路径。研究由用户手动启动，不新增定时任务。
