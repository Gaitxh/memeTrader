# 历史案例只用于测试

历史调研回答的是软件问题，而不是把著名赢家塞回策略：

1. 在选定决策时刻之前，哪些事件证据真正可见？
2. 系统能否列出当时所有同名 Token，而不是只插入最终赢家？
3. 官方准确 CA 能否优先于仿盘；无法区分时能否输出 `WAIT`？
4. 后来的交易所上线、ATH、当前市值、赢家地址和未来钱包标签是否被拒绝？

今天才搜到的旧网页只能标为 `source_claim_only`。网页的 `published_at` 是来源声称时间，系统的 `observed_at` 才是信息边界。只有前向采集日志，或能证明旧时点可用性的可靠档案，才可以用于收益估计。

`research/historical_casebook.json` 不被常驻运行模块导入；它只是研究查询和测试挑战清单。
