## 结论与独立核验

当前早期放量入口仍未证明成本后正期望。部分自然价格路径在高收益观察后直接跳到亏损区域，追踪退出没有中间可用报价。新增实验检验提前兑现部分仓位能否减少这一损失；不声称能预测局部最高点，也不把历史反事实当成实际成交。

独立 Agent 用生产 SQLite 的只读连接复算，限定开仓时间不晚于 `2026-09-08T08:15:59.999999Z`，恢复了报告的基准终局样本。以下反事实采用 4% 卖出折扣、零额外费用，首次成本后 +40% 后的严格更晚同池同源有效观察卖一半，另一半沿用原终局回收额的一半：

## 两个新增独立策略

| 项目 | 对照 `early_impulse_profit_lock_control_v1` | 候选 `early_impulse_profit_lock_40_v1` |
|---|---|---|
| 核心假设 | 同一新前沿的原 60m 退出基准 | 主动部分兑现减少随后跳跌造成的收益回吐 |
| 入场 | 相同的已有 early_impulse 入口 | 与对照完全相同 |
| 单次/容量 | 5U，每臂最多 4 仓 | 5U，每臂最多 4 仓 |
| 原有退出 | 成本后 -20% 硬止损；+30% 激活、15% 回撤追踪；60 分钟上限 | 相同 |
| 新退出 | 无 | 首次成本后 +40% 触发，严格更晚有效原池观察卖出剩余仓位的 50%，仅一次 |

两臂使用新的 `early_impulse_profit_lock_same_fill_v1` 配对组，组大小为 2。共享一次信号和 `source_entry_fill_id`，两臂都满足资金/容量等要求才同时入场；任一臂满仓均不排队补买。新组不与旧三臂绑定，旧策略定义、资金周期和历史保持原样。

使用现成同链、同 Token、同原池、同上游报价与本地观察/入库时间，数据包括价格、流动性、池创建时间、5 分钟买卖笔数及涨跌幅。入场条件仍为池龄不超过 900 秒、流动性至少 5000 USD、5 分钟交易笔数至少 200、涨幅至少 10%；报价至多 15 秒，后确认间隔至多 30 秒、上漂至多 30%/下漂至多 18%。自身激活前沿之前的信号不用于开仓，不回填；每币每臂仅一次生命周期入场。滚动笔数不是独立钱包数或净资金流。

沿用既有市场价格 Paper 执行、配置的不利滑点和逐笔费用。在 4% 买入/4% 卖出、零额外费的测试下，入场信号价为 1 时，名义价涨至 1.50 仍只有成本后 +38.46%，不会触发；1.52 达 +40.31% 才触发。触发帧不成交，重复记录原观察也不成交；其他池不能确认，下一帧若跌至 0.64，就按 0.64 模拟部分卖出，不能保证锁定收益。原池流动性下限、时效和现有更高优先级风险退出保持。

部分卖出复用原执行/分摊路径，不重置持仓时间或历史高点。剩余仓位使用既有“已实现回收 + 剩余仓位成本后价值”的总经济价值判断；不把剩余半仓回报另行归零。一次卖出后 `next_tp_index` 前进，后续再达 +40% 不重复分批卖出。

适用假设 regime 为活跃新池的首次快速上涨、随后存在跳跌危险；并没有可靠的市场状态分类器，也不按日期/时段事后过滤。盈利来源假设是上涨过程中兑现部分风险敞口；失败方式包括入口假阳性、上涨不到阈值、阈值后下一帧直接崩跌、卖出后持续大涨导致右尾截短、原池缺失及实际不可成交。候选多一次 SELL，额外逐笔费用越高越不利。频率由合格新信号和双臂容量共同决定，尚不能给可靠日交易数。最大同时初始投入为每臂 20U、两臂合计 40U；与旧策略的差异仅是这一分批兑现机制，新对照用于消除不同激活时点和容量选择的干扰。

## 验证与判伪

`tests/test_early_impulse_profit_lock.py` 和 `tests/test_early_impulse.py` 共 19 个不同用例最终通过。首次 17 个通过，2 个测试错误地把不可变初始持币量当作剩余量；改为断言 `remaining_quantity_tokens` 后两项通过，生产结算逻辑未改。覆盖旧定义不变、新前沿与幂等注册、禁止用部署前信号买入、同 fill/5U、成本阈值、重复观察不成交、下一原池帧半仓成交、只卖一次、后续 60m 退出，以及暴跌实际价格。

独立账本例：5U 在价格 1、4% 买入滑点下获得 `5/1.04` 个 Token。候选半仓在 1.50、另一半在 1.45 卖出，4% 卖出滑点后总 PnL 为 `(5/1.04)/2*(1.50+1.45)*0.96-5`；对照为 `(5/1.04)*1.45*0.96-5`。测试逐一核对两臂完整 BUY/SELL 净现金流、部分分摊 2.5U、终局成本合计 5U 与仓位 PnL 相等。

自然证据重点观察同 fill 的配对终局 PnL 差、触发率、触发到实际后帧的价格/时间差、主动止盈后继续大涨的机会成本、核销率及扣除新增费用后的尾部损失。只纳入双方已有终局的配对并单列仍开放仓位，按链/日期报告与去掉最大收益配对的敏感性。如果改善依赖少数极端币、实际部分卖出多数跨不过跳跌，或扣新增费用后的配对期望没有改善，则该机制不获支持。不开定时研究，不据短窗提升 Live。
