## 0. 一句话结论

1. 第 82、83 轮都指向"杠杆在覆盖，不在精巧度"。在据此推荐任何东西之前，我测了一个从未测过的
   结构属性——**账本到底代表多少个独立的赌注**：

   | 量 | 实测 |
   |---|---|
   | 已结算仓位 | **4,643** |
   | 不同的**臂** | 188 |
   | **不同的代币** | **94** |
   | **每个代币的仓位数** | **49.4** |
   | 每个 cohort 的仓位数 | 5.6 |

   **∴ 4,643 个仓位不是 4,643 个独立赌注，而是 94 个底层结果被复制了约 50 次。**

2. **损失几乎全部集中在这批被高度复制的代币上**：
   - 94 个代币里 **88 个（93.6%）净亏损**，只有 **6 个（6.4%）净盈利**
   - **最差的 20 个代币承担了总亏损的 67.2%**
   - **在 ≥8 次被开仓的代币（67 个）上占全亏损的 99.9%**；
     只开过 1 次的 25 个代币合计仅 −18.6U
   - 每代币仓位数：p50 **59**、p75 77、p90 94、**max 126**

3. **这修正了第 82 轮的精度（不是方向）。** 第 82 轮报的是 **+1,300U / 4,110 个仓位**；
   而独立单位是 **75 个代币**。按**代币聚类**重算：

   | 量 | 值 |
   |---|---|
   | 每个代币的 delta | p10 **−1.229** / p25 +0.011 / **p50 +2.095** / p75 +22.352 / p90 +64.370 |
   | 规则**改善**的代币 | **59 / 75 = 78.7%** |
   | 规则**恶化**的代币 | 12 / 75 = 16.0% |
   | **代币聚类均值** | **+17.333 U** |
   | **90% CI（按代币聚类）** | **[+12.226, +22.540]** |
   | **是否排除零** | **是** |

4. **∴ 方向成立且有统计支持，但有两个必须一起说的修正：**
   - **效应量应按代币读：每个独立赌注 +17.3U，不是"有 1,300U 可捡"。**
   - **中位数只有 +2.1U，均值 +17.3U —— 收益由少数代币的尾部驱动。**
     第 31 轮那条规则（集中度：去掉最好的几个就没了）在这里适用：
     **"典型代币"的改善很小，大头来自少数几个。**
5. **本轮修正了所有后续前向检验的分母：按代币读，不按仓位读。**

## 1. 为什么这个结构属性重要

1. **仓位级 P&L 高估了独立赌注的数量。** 一个退出规则在同一个价格序列上被约 50 个臂各应用一次，
   所以它"看起来"的效果被复制因子放大了。
2. **风险没有仓位数暗示的那么分散。** 188 个臂在 94 个代币上开仓，
   而 94 个里 88 个亏 —— 这不是分散，是**同一个判断被重复下注**。
3. **任何前向检验的有效样本是代币数（75–94），不是仓位数（4,110–4,643）。**
   这正是项目常设规则与第 26 轮所要求的。

## 3. 一个新的、更根本的观察（本轮副产品）

**94 个代币里只有 6 个净盈利。** 这个比例（6.4%）本身就是对系统的判决：
**在近 4,700 次开仓、188 个臂、大量研究模块之后，能赚钱的底层资产是个位数。**

这解释了为什么退出侧的每一次改进都只能把亏损从 −1,338U 压到 −65U 而**不能翻正**：
**退出规则改变的是"怎么离场"，改变不了"入场选中的资产本身不赚钱"。**

**这与第 43 轮的结论一致并把它推到更清楚的层面**：
第 43 轮测出"+17,620U 属于入场过滤而非退出侧"，本轮给出它的**样本基础**——
**94 个代币、6 个正收益。** 入场侧的改善空间，受限于这 94 个资产的池子有多好；
而池子的大小由观测槽位预算决定（用户决策项，第 73 轮已闭环）。

**∴ 本轮不提出任何改动。** 它做的是把分母摆正，让后续所有结论按正确的单位陈述。
