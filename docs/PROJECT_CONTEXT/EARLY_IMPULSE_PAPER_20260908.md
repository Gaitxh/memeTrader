# 早期上涨机会与退出风险：三组同价入场 Paper 试验

对应 `C2C-20260908-EARLY-RISER-OPPORTUNITY-REFRAME-03`。本轮接受目标修正：先上涨数倍、后来崩跌，可以是值得研究的早期入场机会。六小时存活与否不能代替机会标签；未来最高涨幅也不能代替可执行收益。当前证据支持小额前向试验，未证明 Alpha。

## 独立核验的发现

两个独立 Terra 分支分别复算档案和当前 SQLite 覆盖，Root 检查方法、纠正重叠比较并集成实现。未获得新的 Chat 直接回复，不能把 Agent 结论称作 Chat readback。

档案复用已有 `lifecycle_20260908/lifecycles.jsonl`，不重扫 D: 原始档案。选择合格的第300秒特征，不用整条未来路径 gap/price 筛选；标签另列是否具有可观察的一小时端点。固定条件：5分钟成交笔数≥200、价格相对档案起点上涨≥10%。

较晚日期条件样本中，47.051%达到成本后+30%观察高点，但一小时端点正收益仅20.599%，端点≤−50%占61.576%。462个达到+100%的样本，高点距入场的中位时间33.37分钟，21.43%在15分钟内达到高点。它们中只有378个具有六小时标签，其中65.344%满足旧扫描器的 `up_then_90_drawdown` 路径代理，23.545%六小时端点仍正收益。这不是全部462个的崩跌率，更不是链上确认 Rug。

档案采用下一档案报价及买入×1.04、卖出×0.96的价格调整。它不具备当前生产池/来源/流动性/可卖性和真实成交延迟证明。300秒是距档案首个观察，不能冒充链上建池年龄；涨幅和交易字段的生产映射仍需前向验证。这些日期划分和阈值已经被研究过，不能叫未触碰的样本外验证。MFE、峰值时间均为未来研究标签，代码不会读取。

Root 复算14:16既有自然快照：Runner候选20个具有运行高点的终局仓，已实现−46.0767U、各仓最高经济价值减本金之和+38.1791U，相差84.2558U。9仓曾达到+30%，其中4仓后来因池流动性低于底线写销。对应旧退出对照为21仓、差额51.7013U。各仓最高点不同时发生，也不能保证可卖，故84.26U是诊断回吐的观察量，不是声称可追回的利润。

## 冻结的实现

共同入场：只用部署后当前观察的同 Token、同池、已知上游来源数据；observed≤ingested≤recorded≤decision，观察年龄≤15秒；池龄0..900秒；流动性≥max(5,000U,当前共享底线)；5分钟买卖总笔数≥200、m5价格涨幅≥10%。不额外要求买方占比、h1加速、成交量、三帧效率。新池年龄不等于新Token年龄，这个分支研究当前可交易的新池脉冲，不宣称验证了Token创建早期。

信号后按现有框架等待严格晚于决策的下一观察，同池同上游、间隔≤30秒、仍新鲜且满足流动性底线；相对信号价格漂移限定−18%..+30%。信号帧不能充当成交帧。三臂全部可入场才共享同一个 `source_entry_fill_id`，各有独立账户、独立退出；任一臂满仓会限制匹配组入场，避免用不同币冒充退出对照。

每笔5U，每臂最多4仓，每Token每臂终身一次；无加仓、无回填、无白名单、无排队重放。沿用当前Paper买/卖4%滑点、额外费0U及原池低于共享底线的写销契约。保存的用户执行设置仍由现有机制生效。

| 新策略ID | 退出规则 | 主要待证伪假设 |
|---|---|---|
| `early_impulse_control_15m_v1` | 成本后−20%止损；运行经济收益曾达+30%后，价格自运行高点回落15%退出；最多15分钟 | 集中机会入口配旧退出能否优于无选择的广泛入场 |
| `early_impulse_trailing_60m_v1` | 相同止损和追踪规则；最多60分钟 | 延长时间允许较晚展开的脉冲继续上涨，同时比6小时宽退出少回吐 |
| `early_impulse_probation_60m_v1` | 相同60分钟规则，再加一次10分钟续持检查 | 缺乏恢复的弱势路径能否提前退出，减少成本后亏损和池失效暴露 |

续持检查具体定义：持仓后300..330秒内首个合格行情保存为基准；600..630秒内首个合格行情只判断一次。仅当从未触发共同追踪的+30%运行高点、当前经济价值不高于本金、价格≤基准98%、滚动成交笔数≤基准80%时触发退出。5分钟/10分钟和2%/20%容差是冻结的前向假设，未针对后来赢家调参。

基准与复查必须同原池、同报价provider、同已有持仓数据中断边界。字段缺失、来源变化、中断边界变化或错过窗口，不补做历史判断，保持共同止损/追踪/时限规则。+30%判定刻意复用共同退出所用的持仓运行经济高点：该高点可来自被系统接受的同原池不同报价provider，并非声称全程单源；这只会取消额外的续持卖出，不会制造新的卖出信号。状态写入现有 `capital_exit_state_json`，重启保留；退出仍在触发后的下一有效原池观察模拟成交，止损/普通追踪优先。

## 盈利来源、失败模式与验证

三臂共同适用于年轻池的活跃上涨阶段，尚无日期/链/regime有效性的证明。主要盈利来源假设为早期脉冲在入场后继续扩展，差异在机会结束前能保留多少收益。失败包括假放量、刷单、上涨已末段、短暂冲高、采样遗漏、滑点后无空间、流动性消失。更长持有增加失效暴露；续持检查可能误杀先跌后涨的真机会，检查缺失则不提供额外保护。

历史片段只有30个信号币、22个有兼容下一报价，不能外推日交易频率。实际频率受自然新池、共享观察覆盖及三臂容量共同限制。滚动买卖笔数不是独立钱包数或真实净资金流。仅4%双边滑点即需价格上涨约8.33%才能回本，税费及真实可卖性仍可能恶化收益；MFE统计不是策略期望值。

自然验证保留信号/拒绝原因与下一帧信息，按Token、日期、链和同一入场fill比较：信号分母、时延/漂移、已终局数量、净PnL及中位数、写销率、达到+30/+50/+100%观察高点的比例和保留率、去掉头一/前三赢家后结果、双方均已终局时的配对差。对照组尚开放的仓位不当成0收益。

若增加机会覆盖没有转成成本后收益，或者60分钟/续持检查在匹配样本中不能减少回吐和写销，则反驳相应假设，不能因MFE富集继续宣称成功。后续依据自然证据人工审阅，不启动定时研究、自动改参或自动Live。
