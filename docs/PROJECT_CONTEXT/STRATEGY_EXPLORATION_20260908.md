## 2. 当前结果真正说明什么

上述 2,320 个终结仓记录净损益 **−2,598.07 U**，单仓中位数 **−1.024 U**，Profit Factor **0.473**。先对同 Token 的复制仓求均值、再让 Token 等权，均值仍为 **−0.966 U**，中位数 **−1.006 U**。46 个 Token 为正、120 个为负。复制账户影响规模，不能解释掉亏损方向。

|链|终结账户仓 / Token|记录 PnL U|PF|
|---|---:|---:|---:|
|Solana|855 / 38|−1,156.91|0.417|
|BSC|827 / 56|−1,299.73|0.369|
|Robinhood|638 / 72|−141.42|0.840|

这是多独立账户结果的统计汇总，不是一个真实组合净值。三链样本与时段不等价，不能直接推出固定链权重。flow_burst 的 88 个仓仅涉及 3 个 Token，也不能按 88 个独立样本解释。

当前普通 Paper 为买卖各 4% 不利滑点、额外每 fill 费用默认 0 U。价格不动，往返损失为 `1−0.96/1.04=7.6923%`；单次完整进出仅打平便需市场价格上涨约 **8.3333%**。多次部分退出遇非零每 fill 费用时成本更高。结果含模拟成本，仍未证明真实金额下的链上成交、税费、深度与冲击。

硬止损和池底线核销关联显著尾损；trailing 关联正收益。但退出原因在结果发生后形成，不能据此断言“改成 trailing 就赚钱”。旧诊断的同入场退出消融和追价过滤曾跨窗口改变正负方向，未形成稳定收益证据。历史少数币贡献集中，任何新机制都需要去最佳 Token 后检验。

按小时的表现也不稳定：本窗口 UTC 16 时略正，而单仓中位数仍负，17 时再次为负。这是观察结果，不能将 UTC 小时当作买入规则。更合理的待验证因素是同链机会密度、币龄、原池有效覆盖、价格路径和活动结构；本轮不事后筛选“盈利小时”。

## 4. 外部研究的作用与限制

[Robinhood 的 PEPE 上币公告](https://robinhood.com/us/en/newsroom/robinhood-crypto-expands-offering-with-solana-sol-pepe-pepe-cardano-ada-amp-xrp-xrp-for-u-s-customers/)可核验 2024-11-13 的事件，却不提供上涨前原池历史。公告只能从首次本地收到以后使用，不能反填到早期买入。

[CoinGecko 2025 Meme 报告](https://assets.coingecko.com/reports/2025/CoinGecko-2025-State-of-Memecoins-Report.pdf)描述 BONK、PEPE、WIF 的历史阶段与板块退潮；[Kaiko Q1 2025 报告](https://marketing.kaiko.com/hubfs/Kaiko%20Research%20-%20Quarterly%20Report,%20Q1%202025.pdf)给出部分成名币 CEX 深度恶化的反例。两者支持研究生命周期变化，但 CEX 订单簿深度不能替代本系统 DEX 流动性。

[Chainalysis 的操纵分析](https://www.chainalysis.com/blog/crypto-market-manipulation-wash-trading-pump-and-dump-2025/)给出配对地址制造成交的案例。其地址和金额证据比本系统的聚合笔数丰富，当前不能把高换手率直接判为刷量或真实资金流。

[Catching the Rug 预印本](https://arxiv.org/html/2608.20271v1)研究首五分钟特征与后续失败标签，但排除了首五分钟内已失败的币，且使用钱包/金额特征。没有复现其数据、单位和模型，也没有把风险分类成绩当成可交易收益。Solidus 报告仅取得入口，未采用不可核验的详细金额。

外部历史赢家是事后案例，尚未获得它们上涨之前完整原池/钱包快照和同批发行全集；不能声称已完成无幸存者偏差的赢家预测研究。最有用的新方向是区分价格重估与双边可见数量变化。字段来源为 [DexScreener 官方 API 的 Pair schema](https://docs.dexscreener.com/api/reference)，不增加外部请求。

## 5. 新策略合同与反方条件

共同约束：独立 Paper 账户、5 U 普通买单、每账户最多 4 仓、同原池严格三时钟、禁止使用部署前帧。入场取至少相隔 15 秒的独立观察，最新观察不超过 30 秒；信号后必须另有新原池观察才执行。新数据缺失、来源/池身份变化不能拼接。账户资金、原始历史、旧规则不变，Live 持续锁定。

### A. 双边库存扩张后突破 — inventory_baseline_v1

**假设与盈利来源：** 在价格尚窄幅变化时，base 与 quote 数量先共同增长，随后价格突破，可能区别于仅因价格上涨产生的美元流动性增长，捕捉有后续承接的上涨段。

**数据和特征：** 现有 Dex raw 的 base/quote 数量、priceNative、priceUsd、quoteToken 身份、dexId、labels、原池、池龄、买卖笔数；只接受 BSC/Robinhood、PancakeSwap/Uniswap 且明确仅标记 v2。数量是 displayed inventory proxy，不能证明 LP 注资、可执行深度或无 rebase。

**入场：** 最近三个独立帧 A/B/C；A→B 两边数量均至少 +5%，native/USD 价格均在 ±3%；B→C native 至少 +6%、USD 至少 +3%，两边数量均保留 B 的至少 97%。池龄 2 分钟—24 小时、m5 至少 3 笔，已知池值至少 `max(1000, 当前配置底线)`。符合后在下一独立同来源、同池、同报价币观察成交。

**持仓与退出：** 继承透明基线：−20% 硬止损、收益 +30% 后运行高点回撤 15% 的 trailing、30 分钟最长持仓；没有固定分批止盈。新鲜已知原池低于共享底线仍按既有合同核销；缺失和陈旧不能核销。

**regime：** 有 v2 数量覆盖、从窄幅扩张到突破的阶段。不是全链通用机制，不用时钟小时筛选。

**失败模式：** 捐赠、rebase、转账税、聚合缓存可制造数量变化；突破后仍可能撤池/反转。报价资产波动也会影响美元结果。价格条件和协议限制仅收窄假设，不证明安全。

**频率/成本：** 预期稀疏，实际每日期望笔数未知；最多 4 个同时持仓，复用现有观察，无新增网络预算。6% 的触发变化本身不覆盖往返成本，利润必须来自触发后的延续，不能拿触发前涨幅计利润。

**区别与证伪：** 现有 price_then_depth 使用 USD 池值，本策略使用同原池两边数量。观察去 Token 重复后的净收益、右尾保留、失败率、覆盖率，以及扩张后并未延续的比例；若排除最佳币后收益消失，不能认定 Alpha。

### B. 双边库存突破与收缩退出 — inventory_contraction_v1

**假设：** 双边数量显著收缩而价格暂未跌落时，可能存在比单纯价格止损更早的风险信号。

**入场/数据/regime：** 与 A 完全相同；A/B 必须同时具备额度、槽位和同一后续报价，才能产生共同入场 fill。这个额外账户用于比较真实不同的退出机制，不是重复入场参数。

**退出：** 保留 A 的全部硬止损、trailing、期限和原池底线。在买入后新观察建立数量锚点；base、quote 均降至锚点 85% 以下，同时 native/USD 仍在锚点 ±5%，至少两个相隔 5 秒的新帧确认才产生 SELL，下一有效原池报价执行。间隔超过 60 秒、报价身份变化、字段缺失或请求失败切断确认；不会将恢复帧与缺失前帧拼接。不会因为 API 错误卖出或核销。

**风控/主要失败：** 与 A 同为 5 U/4 仓。库存代理误报可能提前卖掉赢家；真实撤资也可能一步跳到 0，没有提前退出机会。仍无法保证真实成交。除该新增退出以外，保持同样成本和退出基线。

**频率/成本/证伪：** 入场次数与 A 配对；比较同 fill 的成本后净收益差、避免尾损、损失的后续右尾及退出等待。每 Token 先聚合差值，再按日期/链分层；不能将 A/B 收益相加当两个独立成功案例。如果误退出损失大于减少的尾损，否定该退出。

### C. 恐慌修复与成本后空间 — inventory_cost_space_v1

这是进一步丰富并已实现的下一轮方向：让已有反弹机制显式回答“即使回到此前已知价格，是否仍有净空间”。不再创建一个与旧 panic 策略同义的控制账户。

**核心假设：** 在过度反弹后才进入的候选，即使恢复到已知跌前锚点，也可能覆盖不了成本；基于过去锚点的空间约束可能改善选择。

**数据/严格前向特征：** 当前同池最近五分钟独立端点、价格、USD 流动性、池龄、m5 买卖笔数和当前执行滑点/费用。仅用决策前已独立观察的低点之前最高价格作锚点；它不是未来目标、收益预测或可达上界。

**入场：** 保留 panic_reclaim 的池龄至少 15 分钟、池值至少 5,000 U、买单占比至少 55%、相对初端跌幅至少 20%、低点后至少两个上升观察、反弹至少 5%、窗口流动性留存至少 80%。再按信号价 5 U 买入和假设锚点价一次卖出的当前执行合同计算，净空间至少 +10% 才合格。实际依然在之后的新报价成交；跳价会侵蚀该信号时空间，不回填或保证实际收益。

**退出/风控：** 5 U/最多 4 仓；15 分钟最大持有、−20% 硬止损、原有 +30% 卖余仓一半/+80% 卖剩余及 trailing，共享底线和新鲜度不变。没有为了空间计算取消费用。

**regime/盈利来源：** 跌深后重新承接、且离已知跌前价格仍远的情形；赚取后续实际反弹，而非预测新 ATH。

**失败模式：** 旧高只是一次操纵尖峰、永不回归；复苏假信号、跳价、核销。当前选中样本不足以证明空间较大者更赚钱。

**频率/成本/区别/验证：** 相对父机制更稀疏，每日频率未知。显式使用所有已配置模拟成本，不靠细调 panic 阈值制造名称。保留父信号是否成立、空间、拒绝理由、锚点帧 ID/时间。它是独立新账户，未与旧父策略强制同资金、同 frontier、同机会配对；任何未来与父策略比较都必须先重建同一合格机会集，不能直接比较账户总 PnL 宣称过滤有效。

## 6. 交叉验证计划与本轮没有完成的验证

本轮 16 案例决策均位于同一 UTC 日，部分序列只有一个端点，且从已成交/终结仓取样。因此不能诚实地给出日期隔离的收益交叉验证成绩，也没有训练一个“成功币分类器”。已验证的是字段、时钟、身份、边界和模拟执行，不是盈利。

自然前向证伪按以下顺序进行：

1. 先报告所有被观察候选的字段/协议/来源可用性、缺失、拒绝、槽位和配对失败；不只看买入或赢家。
2. Token 全部 episode 同组；日期块在标签完全可见后才能分析，最后未结束持仓保留删失状态。短窗和不同 regime 不混称独立验证集。
3. A/B 先做同 fill 的差值；C 先做共同候选空间与拒绝后实际端点覆盖研究。既计算避开的亏损，也计算错过的右尾。
4. 统计成本后均值/中位数、PF、尾损、去最佳 Token/前三 Token、链/池龄/日期分层。重叠 m5 窗口不是独立五分钟成交，不拿窗口差分当净流入。
5. 阈值本轮未由获利样本拟合。未来若改阈值，需新版本、自己的 frontier；不覆盖本轮策略。证据不足时不扩大风险，不进入 Live。

未来还值得研究：原池可见数量变化与价格路径的条件关系，以及同币不同 episode 为何表现相反。当前已把前者的入场/退出和后者的成本空间选择器落到本轮三个实验中。真正的钱包金额、税费、资金净流入、跨池可执行深度仍缺稳定低成本事实输入，未用笔数或 USD 流动性伪造这些特征。
