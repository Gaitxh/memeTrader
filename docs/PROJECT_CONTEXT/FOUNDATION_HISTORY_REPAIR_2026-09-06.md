2. 持仓与精确池 Dex 请求遇429时，HTTP 层原地重试最多等待15秒，占用同host排队。现在把这些请求交回运行时退避，普通低频发现原行为保留。
3. 补源请求返回时主路可能已恢复。返回后和落地前重验缺口，避免旧响应覆盖新行情或继续消耗CG额度。主源忙/退避只跳过Dex，CoinGecko仍按原独立配额和每池60秒限制补缺；测试拦截并修正了曾一度把CG也暂停的未部署回归。不进行跨源价格重复一致性验证。
4. CoinGecko EVM resource ID 大小写导致拒绝合法资源，现按0x地址不区分大小写，Solana仍区分。
5. Jupiter 通用拒绝缺少分类。单次官方quote请求成功，不能据此证明历史119次失败的根因；解析器现在报告协议不匹配的安全字段名，不输出密钥或原始响应。
6. 交易历史后端近期窗口加前端30条截断，仓位拼接因而可能有SELL无BUY。新增独立50条分页接口，固定 through_id，上/下页可遍历当前账期全部记录；可按本次持仓过滤，展示完整日期、Token、操作、净现金流、已实现PNL、污染/纠正及独立补款，保留原始账本展开项。历史按需读取，不加入后台轮询，不扩大实时全量载荷。
