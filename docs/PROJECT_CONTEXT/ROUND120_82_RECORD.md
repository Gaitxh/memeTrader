## 0. 一句话结论

1. 第 81 轮明确写下："本检验只看了最终核销的仓位；更激进的退出也会作用在最终回本或跑成大金狗的
   仓位上，而那部分代价完全没有测量。"**本轮把它测了。**
2. **全账本（3,878 个有可用 mark 的已结算仓位，实际合计 −1,255.7 U-equiv）：**

   | 规则 | 合计 | 均值 | 相对实际 |
   |---|---|---|---|
   | **实际** | **−1,255.7** | −0.324 | — |
   | 从入场武装，回撤 10% | −115.8 | −0.030 | +1,139.9 |
   | 从入场武装，回撤 15% | −112.5 | −0.029 | +1,143.2 |
   | **从入场武装，回撤 25%** | **−50.3** | −0.013 | **+1,205.4** |
   | 从入场武装，回撤 30% | −48.6 | −0.013 | +1,207.1 |
   | 从入场武装，回撤 50% | −70.7 | −0.018 | +1,185.0 |

3. **赢家没有因此变差，反而变好。** 按实际盈亏拆分：

   | 组 | n | 实际合计 | 从入场武装 dd25% | 差 |
   |---|---|---|---|---|
   | **实际赢家**（realised > 0） | 1,102 | **+248.1** | **+340.0** | **+91.9** |
   | 实际亏损者 | 2,776 | −1,503.8 | −390.3 | +1,113.5 |

   **∴ 收益不是靠"砍掉赢家"换来的——赢家那一组也改善了 +91.9U。**
   这是第 81 轮最担心的那一点，而它被否证了。
4. **我先验证了自己方法里的一个偏置（截断），它不成立。** "实际"是按仓位的**最后一个 mark**
   计价的，而提前退出的规则按自己的出场 mark 计价——若某些仓位的 mark 早早停止，
   就会**系统性偏向提前退出的规则**。实测：**全部 3,880 个案例中，最后一个生期 mark 距平仓
   p50 = 4 秒、p90 = 9 秒，超过 60 秒的有 0 个（0.0%）**；
   限制在"最后 mark 距平仓 ≤15 秒"的子集上重跑，**结论不变**（−50.6，+1,203.7）。
   **∴ 那个 +1,200U 不是截断 artifact。**
5. **但我不把它当成"应当改参数"的理由**（§4 说明边界），
   而是把它当成**一个具体、可前向验证的假设**。

## 2. 规则对比的细节（可复现）

- **总体**：每个位置**有可用 mark**（≥3 个生期 mark）才纳入；**排除 525 个并报出数量**
  （第 64 轮规则：排除数必须报出，不得静默过滤）。
- **因果性**：running high **只取当前及之前的 mark**；**成交价取下一个 mark**；
  核用引擎自己的 `0.96*R − 1`（第 69 轮）。
- **计价时机**：每个规则按**它自己的出场 mark** 计价；"实际"按最后一个 mark 计价。
  **这一条是我自己方法里的偏置来源，已在 §0.4 单独验证并否证。**
- **参数稳健性**：从入场武装的 7 个回撤档位（10%–50%）**全部落在 −48.6 到 −124.8 之间**，
  即全部大幅优于实际。**参数不敏感 → 第 26 轮的择优陷阱被削弱**（不是消除）。

## 3. 一个我必须说清的细节：部署形状的对比不能跨臂直接比

同一批数据上，"武装在 +45%"（−48.0）看起来**优于**"从入场武装"（−50.3）。
**但这两个模拟都是把同一个阈值套在全部仓位上，而各臂的实际激活线是 0.20–0.60。**
逐臂合约的实测（第 81 轮，核销队列内）显示：按各臂**自己的**合约武装得 **+122.8**，
而从入场武装得 **+114~+120**——**两者几乎相同**。

**∴ 更准确的表述是：**
> **在这份账本上，"追踪退出怎么武装"这个选择的影响很小（±7U 量级），
> 而"追踪退出是否被应用"的影响很大（+1,200U 量级）。**

**真正的差距不在激活线，而在这些仓位身上根本没有生效的追踪退出。**
（第 77 轮已测：低阈值/无追踪的臂上，78% 的核销仓位从未触及激活线；
而第 76 轮测出追踪退出只捕获中位峰值的 34.9%。）

## 4. 这**不**是"应当改参数"的理由（边界必须一起读）

**它是上界，且有几条是实质性的：**

1. **mark 流是重复为主的**（第 79 轮：不同价格数/mark 数 p50 = 0.24）。
   规则在两个 mark 之间的真实走法**看不到**，所以触发点与成交价都可能偏离。
2. **4% 不利滑点未建模**，只用引擎自己的 0.96 卖出折价。
3. **单 epoch 样本内。** 参数不敏感削弱了择优风险，但**没有消除**它。
4. **它没有回答"实盘能不能做到"**：mark 是持仓驱动的，真实成交的价格可能更差。
5. **第 43 轮的既有结论仍然适用于止盈侧**（在保留账簿上，止盈的样本内边际价值约为 0）——
   **本轮的结论是关于追踪退出，不是止盈**，两者不能互相引用。

**∴ 本轮不改任何参数、不新建模块。**
按用户规则，任何退出改动必须是**额外策略模块 + 自己的前向证据**。
**本轮的贡献是把这个假设说得足够具体，可以被前向检验：**

> **假设**：一个**从入场就武装的追踪回撤退出**（回撤 25–30%），
> 在同一批持仓上会把账本从 −1,256U 改善到约 −50U，
> **且不会牺牲赢家**（实测赢家组 +91.9U）。
> **未验证**：实盘可执行性、跨 epoch 稳定性、以及它与其他退出规则的交互。
