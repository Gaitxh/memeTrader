## 4. 用第 50 轮的仪器检验"用发现 role 分配槽位"——**未通过**

**这是本任务明确要求我探索的方向**（"对于受资源限制暂时无法直接获取的数据……请优先基于现有可获得的
数据与特征，设计高质量的派生/近似特征"）。方案的 P1 提议：**把推广/身份 surface 用作"槽位分配"特征，
而不是入场证据**——因为槽位才是稀缺资源，而"决定看哪个池子"不会让它变成决策证据，所以不违反冻结契约。

**合法性前提已满足**：discovery role 在**发现那一刻**就已知，早于首个行情观测，
所以它是一个**时点合法**的特征（与第 50 轮抓到的"统计决策后帧数"完全不同）。
