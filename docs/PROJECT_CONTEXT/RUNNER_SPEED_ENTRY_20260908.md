## 裁决与新策略合同

**接受为小额、可证伪的前向实验；拒绝“180s 已证最优”“跨链通用”“已发现正 Alpha”的解释。** 支持实施的新增机制是：原池较早达到原 Runner 的需求质量，配合更早兑现；支持来自相邻池龄敏感性、保留失败分母的机会富集及实际收益回吐，强度只够检验假设。

12 个 ≤180s 信号中，5 个为原 explosive、7 个为 persistent 路线；只有 3 个同时满足现有 early_impulse（≥200 笔）条件，没有一个满足旧 flash-tail 的完整入口（<120s、前55m零交易、5m量<1000U等）。原 Runner 两臂窗口为 5400s 且没有此两级止盈。因此新组不是旧策略改名或已有账户参数覆盖。

| 合同 | 新同成交对照 `runner_ultra_early_control_v1` | 新候选 `runner_ultra_early_lock_v1` |
|---|---|---|
| 入口 | 原 `runner_signal`，仅最大信号原池龄收窄为 180s | 完全相同 |
| 预算 | 每次 5U、每臂最多 4 仓，独立账户余额约束 | 相同 |
| 保留退出 | 成本后 -20% 硬止损；+30% 激活/15% 回撤追踪；15m 上限 | 相同 |
| 主动兑现 | 无 | 成本后 +40% 卖剩余50%；部分成交后总经济收益 +80% 卖余下 |

数据及原逻辑：同 Token/原池/上游的新鲜价格、至少 5000U 流动性、当时池龄/Token龄、5m/1h 交易笔数和成交量、买入占比、量/流动性及已有持续路径。保留 Runner 的爆发或持续质量、迁移排除、15 秒新鲜度、30 秒确认间隔、价格漂移及每币一次规则。180s 限制作用于信号观察，下一成交帧可以稍晚于此池龄，不能把成交时间冒充信号时间。

新 `runner_ultra_early_same_fill_v1` 组大小 2，独立于旧组；两臂同一合格信号和同一非空 `source_entry_fill_id`，任一满仓均不排队补买。真正新激活前沿后才能产生信号，不回填。候选两级均先生成意图，严格更晚有效原池帧才模拟成交，现有风控优先；跳跌、过期、缺池不能假装高价兑现。不重置部分成交后的计时、高点或经济价值。

该配对能隔离早期入组后的退出差异，**不能单靠这两臂证明池龄筛选本身的因果收益**。原较宽 Runner 只能提供带不同容量和入组历史的描述性参照。180s 为冻结实验边界，未据同一数据最优值继续微调，不另加链/时段事后限制。

适用假设：新池在前三分钟形成可观察需求质量、随后既有短时右尾又有跳跌风险。收益来源是捕获早期放量并提前减少暴露；失败模式包括操纵成交、虚假报价/流动性、来不及确认、未达阈值先亏损、过早兑现截断持续赢家、同源报价空档，以及对照/候选退出差异造成后续组容量限制。多一次卖出对额外逐笔费敏感；默认4%/4%不利滑点、0额外费仍沿用当前激活执行合同，未新增深度/精确报价要求。此前约4.74小时仅12个该类首次信号且后段为空，不能给稳定日频；最多同时初始占用两臂合计40U。
