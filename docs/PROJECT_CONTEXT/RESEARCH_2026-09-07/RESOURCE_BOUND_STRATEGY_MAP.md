## 4. 六个可收敛候选：行为、对照、停止条件

以下不是六项已授权部署清单，也不是要求六个必须全部新增。阈值应由根代理结合既有输入实际覆盖冻结；不进行参数搜索。每个新增臂从真实部署frontier起，既有资金/策略/开放仓不动。普通成本、公共风险和严格后观察执行保持。

### A. 净盈利支撑状态的进展时钟豁免（优先）

在与212/217相同入场、相同成本和公共退出下，只处理无进展deadline。候选必须同时满足当前模拟净经济价值>总投入、先前已用至少两个独立观测确认的支撑仍完整，才暂停这一条时钟退出；支撑失守、净盈利消失或证据链断裂则取消许可，按新鲜帧重新判定。支撑不能事后用整个持仓最低点挑选；首次确认时冻结，更新只能向前。

对照不加此许可；不是给全部亏损仓延时。与218区别：218三帧略改善即可给一次120秒，不要求净盈利/冻结支撑；此处检验状态而非时间参数。硬止损、trail、max_hold、原池低liq处理不豁免。反证：多留的盈利仓最终更多回吐/核销，或改善仅来自一个共同Token。参考 `research_round2.py:94–106`。

### B. 可见原池衰退缓冲时间（优先候选）

用已经收到的同池同源正liq序列，按真实观测时距估计下降速度，描述“当前liq距有效共享门槛，在近期下降速度下剩余多少时间”。只有已观察持续下降才产生早退意向，恢复/换源/断流使这段外推失效；不因时间流逝凭空延长下降序列。候选在缓冲短于冻结预算时增加退出；对照保持共同原退出。

不是预测LP撤池，也不是延迟门槛核销。价格与USD liq机械关联可能产生假信号，需在有相同价格回撤但不同liq变化的自然组中解释，不能把未知当安全或危险。已有190是两次价跌且liq不增且未回本，未做此距离/速度行为，`strategy_revisions.py:439–451`。

### C. 年轻池有效观察寿命归一化加速（依赖本轮字段实证）

明确比较对象为已有m5/h1聚合或现有局部窗口，修正不足完整窗口的年轻生命周期分母；仍称聚合活动代理，不称实际净流。控制共享原入场机会和普通退出，candidate只增加/替换事前冻结的归一化加速规则。不能把池龄直接当本机已观察时长，更不能用日后创建时间回填。

### D. 已知急跌参考位下的成本后反弹空间（有限入场消融）

从真实首涨时点进入状态，冻结当时已知平台上下边界；降温阶段价格仍保持平台、聚合活动相对首涨下降但不是必须静默；随后活动恢复且突破平台上沿才发信号。它应覆盖“没有5–15%价格回撤却完成换手平台”的路径，才可能区别133/207。
