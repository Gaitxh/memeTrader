## 2. 本轮真正增加的事实

### 2.1 新收益和旧结论并不矛盾，关键是窗口与集中度

09:19:47Z之后的831笔记录为425 BUY、359 SELL、47 WRITEOFF。425新仓只有33独立Token，51/224账户有新BUY；369已终结、56仍开放。终结仓跨账户描述性相加为+145.5639U，但最佳Token贡献+415.5879U，占正Token贡献78.21%；去掉它为−270.0240U。不得将多账户相加当可投资组合，也不把开放仓收益填零。剔除大赢家只显示脆弱性，不额外规定趋势策略剔除赢家后仍须盈利。

同入场13组共同终结样本中，进展时钟相对基线3改善/2恶化/8相同，净差+4.398552U，中位差0。slow_grace、response_exhaustion在本窗没有新的终结差异；这不足以断言从未触发，却足以阻止按名字认定增益。

## 4. 第一批三个可执行方案

### A. 池龄归一化活动加速

ID：`resource_age_rate_control_v1` / `resource_age_rate_candidate_v1`。

**假设/盈利来源：**剥离新池未存续时间造成的加速放大，减少无真实活动扩张的成本损耗。数据为当前同响应池龄、m5/h1成交笔数及成交额；全部是报告活动，不是净资金或独立钱包。

**共同入场：**900秒<池龄<21600秒；m5笔数≥8或成交额≥1000；交易和金额两种前段基线均为正，排除缺失/负差/零基线；旧笔数或成交额速率比≥3。阈值沿用现行flow-burst，没有搜索新数值。

**候选唯一变化：**令T=min(55,池龄分钟−5)，将原速率比乘T/55，要求笔数或金额调整后仍≥3。≥60分钟时两种定义一致。第一轮以共同正基线隔离时间分母，不同时检验“零基线首次活动”。

**退出/风险：**两臂完全相同，遵守第3节。**regime：**正在扩张的15分钟至6小时池，差异主要在前1小时。**频率：**未知；接受集合是共同机会子集，独立资金下成交总数不保证同比。

**反证/验证：**被拒绝恒速池可能贡献主要右尾。报告共同机会、拒绝与接受子集的对照实际净结果、缺后帧和资金阻断；不能把少交易本身当成功。

### B. 涨后降温、聚合端点守位

ID：`resource_cooling_hold_control_v1` / `resource_cooling_hold_candidate_v1`。

**假设/盈利来源：**此前上涨后活动降低而价格端点未明显退回，可能提供区别于持续追热度的延续机会。它是便宜的端点假设，第一版不声称已经发生完整横盘平台或第二次突破。

**数据/共同入场：**1–24小时池；m5笔数≥8、成交额>0；上述两种正前段基线和m5/h1价格变化均可用。g5=log(1+r5)，g55=log(1+r60)−g5；此前g55至少达到当前一买一卖成本的对数尺度。非零每填费用也计入尺度，计算为log((1+b)/(1−s))+log(1+2f/N)，N为5U名义额。这只要求此前位移有经济量级，不预测未来收益。

**候选唯一变化：**−0.25×g55≤g5≤0，且(m5成交额/5)/((h1−m5成交额)/55)<1。四分之一是沿用前一Chat明确提出的待验证研究选择，不是本窗训练得到。对照满足相同背景与字段，但不加降温守位条件；双方同一决策等待后帧。

**退出/风险：**与对照共同基线相同，不附加延期或“修复区必回”假设。**regime：**已上涨、活动降温阶段。**频率/成本：**未知，比完整全年龄Broad窄；一笔仍承担完整往返成本。

**区别/反证：**现有pullback要求明显回撤/收复，本臂可在横向端点保持时进入；不要求新9帧路径。持续放量赢家会被放弃，死寂/陈旧价也会伪装稳定。保留缺字段原因、未选中机会与右尾代价，不能以更低波动代替净收益。

### C. 净盈利且已确认支撑保持时，暂缓进展时钟

ID：`resource_profit_structure_control_v1` / `resource_profit_structure_candidate_v1`。

**假设/盈利来源：**同样没有新高，成本后盈利整理与失败停滞应有不同持有动作；尽量保留慢收益，又不无限拖延亏损。由本窗clock三改善两恶化和明确慢赢家反例提出，不宣称可以准确辨别晚崩。

**入场：**完整复用finalist_progress_clock的Broad共同实际入场。**数据：**实际累计回款＋剩余仓位按卖出成本估值、原池价格/流动性、来源、观察时间，不使用假设已回款。

**候选唯一变化：**仍使用原1%本金进展尺度和180秒无进展时钟。连续独立接受的3个价格中，只有中点严格低于两侧，才在第三点到达时确认支撑；后续确认的更高低点才上移。时钟到期时，只有当前净经济权益>总投入、价格未跌破该支撑、流动性至少保留支撑观察值85%，才豁免这次时钟SELL。时钟不清零；条件消失后按已经到期的时钟形成SELL。

**风控：**仍保留公共硬止损/追踪/原池风险/max_hold。源切换、超过60秒缺口清掉旧支撑；没有有效支撑或已经净亏不授予豁免。重复/未来/过时帧不累计。最少5秒独立间隔和15秒新鲜度沿用已有退出合同。支撑仅是已观察点，不承诺下一帧成交价。

**regime/频率：**盈利但短期无进展的仓位，专属触发频率未知。**成本：**完整实际账本，首轮不分批、不加仓。**区别：**原slow-grace是一段固定120秒延期、只要求三帧持续改善；本臂由净盈利/确认支撑决定时钟适用状态。

**反证/验证：**一并统计获准持有后更亏、失守后的后帧滑落，以及保住的右尾。公平比较必须有共同实际BUY，不能用父策略最好卖点拼收益。
