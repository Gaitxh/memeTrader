# 外部评审纠错台账

2026-09-07，Codex根代理独立打开论文原页核验。R1原文作为历史评审保留，不静默改写；最终分析必须采用本页纠正。

## 1. 毕业率研究不是完整24小时成功率

R1_EXTERNAL_RESEARCH将0.198%称为24h毕业率并解释为较2025年下降三倍，超出了最新版证据。[2607.02823 v3](https://arxiv.org/abs/2607.02823v3)（2026-08-17修订）明确：采集实际约只覆盖发行后六分钟，因此0.198%是快时段覆盖结果/24h下界；3.18倍比较只是下降幅度的上界，真实变化无法从该数据确定。不能据此硬设本系统regime，也不能将漏观察解释为失败。

## 2. 钱包研究已修正机械污染

R1引用约132%买方及136%资金提升、216%placebo，不能作为最新主结果。[2607.02795 v3](https://arxiv.org/abs/2607.02795v3)（2026-08-03修订）排除钱包群自身事件并匹配后，30分钟买方数关联为+16.1%（95%区间13.0%–19.4%），SOL流入+6.3%（-0.5%–15.1%，无法排除0）；活动匹配placebo中位+189.6%被作者明确视为估计偏差诊断，不是有效的因果负对照。研究关联不能当可复制钱包alpha。

## 3. BONK日期冲突

R1外部评审写2022-12-08；独立案例报告引用CoinGecko研究为2022-12-25。当前不据此构造事件t0；最终若涉及该日期须以定义明确的一手发行/交易证据核对，不能把信息页登记日等同首池/发行。BONK仅作有身份边界的历史案例，不进入本地前向特征。
