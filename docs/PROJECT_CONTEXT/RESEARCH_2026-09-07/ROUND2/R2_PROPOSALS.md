## 根代理拟选的新行为轴（不预先强行全做）

1. **成交追价预算**：同一宽入场信号→真正下一帧，独立候选仅在该帧涨价不超当时往返成本带时买；对照照买；veto不得连带取消对照、不得在回落后重放同信号。当前entry_signal_price不等于真实signal，必须用fill_signal_snapshot_id主键。宽松预算来自成本不是赢家拟合。
2. **缓慢稳定持有许可**：与无进展180秒退出作新独立对照；出现持续小幅净经济改善、liq留存与非恶化活动时只准一次有界延期，普通硬止损/尾部保护/maxhold不变。反证：延期主要增加晚崩；不能把健康表面等同可卖保证。
3. **活动边际响应耗尽**：至少3个独立5–60秒帧，报告m5活动上升但价格增量由正→近零且买卖结构向卖方转；未要求价格已下跌。与旧activity_failure方向不同，rolling差分只是代理。高频重叠窗口效应要列反证。
4. **利润回吐持续时间**：净值曾覆盖成本并有盈利，回落到事先利润边界下持续达到预置预算才退出；恢复则取消计时。区别于幅度瞬时锁盈；断流/换源不得伪累计。
5. **部分兑现后的runner重新资格**：实际partial fill后冻结余仓新epoch，不拼旧高点；限定时间内出现新余仓经济高点且原池留存才继续，否则退出余仓。与第一次留runner不同。须独立partial baseline。
6. **卖笔扩张、价位稳而非跌的分配风险**：从买占优切为连续卖占优、价格无净经济进展时退出；与高买笔/涨价仍可能失败对照，不能叫实际资金流。
