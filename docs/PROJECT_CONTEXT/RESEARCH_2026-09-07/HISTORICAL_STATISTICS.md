## 指标定义与不可混同的口径

原始 realized PnL 来自交易账本逐笔求和，包含开放仓的已实现部分；“闭环 PnL”只纳入截止前 position 为 closed/written_off、存在恰好一笔 BUY 且至少一笔 SELL/WRITEOFF 的完整生命周期。核销是账本终止事件，不是可实现的卖出成交。胜率、期望、PF、中位数、10% 双侧截尾均值、5%/95% 分位、尾部和持有时间均以这些生命周期为单位。PF 无亏损分母时是未知状态，不写成有限高分。

“移除最佳 1/3 笔”与“移除最佳 1/3 token”分别记录。token 聚类用带链前缀的完整 token ID，同一 token 多策略或多次入场不能视为独立抽样。正收益集中度以**正 token 聚合 PnL 总额**为分母；版本汇总是各独立虚拟账户投影的描述性总和，不是一个可投资组合的收益率。

主账本所有合格闭环的 `sum(realized_pnl)` 与 `sum(net_cash_flow)` 最大差异为 **5.684e-14 U**，没有超过 0.01 U 的差异。这证明本次原始算术对账一致；不能证明报价真实可成交、早期执行模型正确或策略有效。

部署时间优先采用独立 activation 表/追加策略激活；缺失独立激活证据的早期版本只标登记时间代理，不能把已登记 70 多小时误写成持续交易 70 多小时。记录了入口停止时间、可证明的入口开放时长、实际 max-hold 成熟条数，以及截止时仍开放的右删失样本。

`descriptive_20_roundtrips_10_tokens` 仅说明描述性样本量，不是实验预注册门槛或盈利资格；当前 92 个 arm 达到这个数量标签，仍然只有 1.29 小时。未计算显著性、置信区间或校正多重选择，不能据排行榜推广。

可继续研究的机制线索是：尽早区分衰减与持续、减少无效长持、验证行情完整性下的 next-observed 退出，以及用相同 cohort/token 对照检验 wallet/叙事/资金信息是否提供额外价值。当前配对里 `l0_continuation_failure` 的相对少亏可以成为机制检验起点；`l0_profit_lock` 和 conditional runner 的负差值需要保留，不能只展示正例。

新方案应作为新增 ID 的严格前向实验，不复用这些历史正收益作入场特征，不移动已冻结的资金/策略边界。此报告支持提出受限、可证伪的研究候选；没有给任何 arm Paper 自动推广、Live 或“已验证 alpha”资格。
