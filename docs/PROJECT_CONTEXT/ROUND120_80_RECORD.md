## 3. 第 79 轮更正了什么、保留了什么

### 撤回

> "核销所依据的证据从未进入 mark 历史 → **核销不可审计**。"

**撤回。** 准确表述：**决定性观测不在 mark 历史里**（因为机制用的是单独的重新报价），
**但证据完整保留在 `chain_meme_trader_marks.trigger_evidence_json` 里**。
**核销是可以审计的，只是要从 marks 表读，而且现有读数工具没有暴露这些字段。**
**缺口在读数工具，不在数据。**

### 保留（第 79 轮仍然成立的部分）

- **mark 历史 76% 是重复值**（不同价格数/mark 数 p50 = 0.24，60.1% 的最后 5 个 mark 完全不变）
  → **这张表不能支撑逐帧退出规则回测**，任何在这张表上跑的回测都会报告"从不触发"，
  那是数据的性质而不是规则的性质。
- **75.4% 的核销在这里显示最后一个 mark 仍在下限之上** —— 这是**事实陈述**，且现在有了解释
  （决定性证据在另一张表），**不再是异常**。

### 第 80 轮新增的否证

**第 79 轮提出的 H1（"观测早已停止，核销在盲区里开火"）被否证**：

**核销路径的间隔是全部路径里最短的**，所以它不是"观察不到"，而恰恰相反。
且 **88–99% 的 token 在平仓之后仍有 mark**（说明观测在平仓后继续），
