## 4. 本轮已证实并修复的学习语义

旧账本只把闭仓结果归给事件最早 60 秒合格来源。这对“谁先发现”合理，却不能回答“入场时哪些新证据支持了决策”。从本版本起，新闭仓前向保存两个独立口径：

- `discovery_lead`：最早 60 秒合格证据；保持原学习门，只能作为观察轮换的 Paper 次级验证。
- `decision_support`：开仓前本机已知的全部合格 `feature/confirmation`，同一实体/来源只保留最近一条以防重复发稿放大；仅用于 Sources 审计展示，绝不进入轮换、证据权重、策略或仓位。

两者分别归一化，同一闭仓仍只是一笔交易。旧 r6 闭仓结果保持 discovery 口径，不回填 decision-support，因此网页会如实显示旧样本该栏尚未观察。
