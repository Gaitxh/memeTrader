所有信号要求部署后observed≤ingested≤recorded≤decision，最新帧≤15秒，同池同源连续记录；Quiet Renewal还核查间隔内未选帧。买入必须使用信号之后的新原池观察，≤30秒、上漂≤30%/下漂≤18%，执行当前不利滑点及费用。峰值仅运行高点，无法保证卖到局部最高点。

适用状态分别为早期需求延续、压缩后需求恢复；时间只是窗口，不是Alpha。前者盈利来源假设是持续右尾，后者是突破后持续需求。预计频率低且尚无法量化；现有每链/生命周期观察名额限制样本覆盖，不能承诺每日命中上涨币。不新增网络轮询、不放宽身份/新鲜度/原池底线。未来自然验证应按独立Token及日期比较净收益、尾部贡献、回撤、失败率和配对退出差异，同时单列未成交/缺行情；不得只报告已买赢家。
