所有信号要求部署后observed≤ingested≤recorded≤decision，最新帧≤15秒，同池同源连续记录；Quiet Renewal还核查间隔内未选帧。买入必须使用信号之后的新原池观察，≤30秒、上漂≤30%/下漂≤18%，执行当前不利滑点及费用。峰值仅运行高点，无法保证卖到局部最高点。

适用状态分别为早期需求延续、压缩后需求恢复；时间只是窗口，不是Alpha。前者盈利来源假设是持续右尾，后者是突破后持续需求。预计频率低且尚无法量化；现有每链/生命周期观察名额限制样本覆盖，不能承诺每日命中上涨币。不新增网络轮询、不放宽身份/新鲜度/原池底线。未来自然验证应按独立Token及日期比较净收益、尾部贡献、回撤、失败率和配对退出差异，同时单列未成交/缺行情；不得只报告已买赢家。

## 独立评审后的实证与修复（13:22）

05:16:37 UTC只读采集的自然数据：Runner两臂各15个独立Token，均已平仓；持有右尾臂累计已实现−37.216996U、旧退出−24.316027U，差−12.900969U（每Token约−0.8601U）。此小窗口具体反驳“延长持有已优于普通退出”，但不是长期定论。Quiet两臂0仓，近期1000条评估尾窗中各628次/59币参与判断，227次等待底部、175次市场字段/流动性未满足、226次时间或缺口边界，不能称其胜率为零。证据natural_first_review.json。

采纳：先保证路径连续与退出状态正确，再积累未来独立Token/日期样本。拒绝：把更短的底部窗口加一项流动性门伪装成新机制；扩大仓位；用现有缺失历史声称0–5分钟捕获能力。保持现有两个机制和退出对照，不增加无意义变体。无额外费的当前执行回本原始涨幅为1.04/0.96−1=8.333%，不是0.96平方模型。

已复现两项工程缺陷并修复，不改变任何策略参数/追加合同或历史记录：

1. Runner持续路径仅核查3个抽样点，可能跳过其中的换源或低流动性帧。现在对选定首末之间实际帧也核查时间、身份、来源和原池下限，仍仅用原3点计算既有形态指标；单帧爆发路由保持原合同。
2. 97%高点回收的预警清除被放在较大回撤分支，正常回收无法进入该分支。价格100→97→94→91→88→84→98→83会沿用84时的旧警报并误判二次破位。现在每帧先按已冻结97%条件清除旧警报，新回撤建立新状态。
