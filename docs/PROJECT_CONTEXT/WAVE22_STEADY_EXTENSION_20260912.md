### 2b. 顺带定位并移除一个我自己加的、未被实测支持的过滤条件
`survivable_steady_mid` 首次加载后 **ready 仍为 0**。逐条件计数给出原因：

| 计数（481 帧） | 值 |
|---|---|
| `mid_chain`（池龄+FDV5–20+深度≥10000） | **86（17.9%）** |
| `mid_chain_share55`（再加买盘≥55%） | **0（0.0%）** |
| `share_ge_55`（全体） | 267（55.5%） |

→ **引擎里落在 5–20 安全带且池龄 30–180 分钟的池子，买盘占比几乎从不 ≥55%（卖盘主导）**。而"买盘≥55%"是**我自己加的过滤条件**——第 3 轮的写销带实测只用了 **FDV/深度 与 池龄**，从未包含买盘占比。因此本轮**移除该条件**而非继续调参。

移除后实测：`survivable_steady_mid` **ready = 92**（此前 0），该臂已开仓。
