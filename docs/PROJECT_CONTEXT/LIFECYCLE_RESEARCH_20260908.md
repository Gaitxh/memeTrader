## 2. 因果规则与标签

每币分别在首次本地观测后 5、15、60 分钟建立固定 landmark；主分析只用 5 分钟，其他时点独立报告，不把同币多个时点合成独立样本。特征使用当时已观察的右闭 5 分钟窗口，检查原始中间帧，最大间隙 30 秒；独立价格点间隔至少 15 秒、至少 16 点，跨度至少 280 秒。入场为信号之后第一条报价，最多等 15 秒。15 分钟、1 小时、6 小时终点也要求完整连续窗口和及时报价。缺口、窗口不足、跨日期分区边界均为 unknown，不能伪装成亏损或安全。

分区按 Token 首次观测日：TRAIN 在 2026-02-01 前，VALIDATE 在 2026-05-01 前，TEST 为之后数据。剔除前轮已检查的 1,200 Token 后再做预测方向比较。因为本轮看过 TEST 并据此提出实验，TEST 只能称本轮日期外推检查，**下一阶段真正未见样本来自部署后的自然前向**。档案入库选择和缺失过程仍可能有选择偏差；Token 地址去重也不等于同一操盘者或关联池独立。

价格路径近似净收益为 `终点价格 / 次报价入场价格 × 0.96 / 1.04 - 1`。该表只计双边 4% 不利滑点；没有把未知 gas、税费、冲击、无法卖出当成已验证。后续资金实验另做每笔额外费用敏感性。所有数值均不能直接称实际交易 PnL。

以下互斥后验类别按优先级划分：

| 类别 | 固定研究定义 | 能证明什么 |
|---|---|---|
| 上涨后急剧坍塌 | 已有相对入场至少 50% 上涨；随后不超过 30 秒的一步跌至上一报价的 10% 以下，下一报价仍低于跌前 15% | 观察到了价格坍塌；没有链上撤池证据，不能称确认 Rug |
| 两端盈利路径（原标签 durable_runner） | 1h 和 6h 近似成本后均至少 +20%，且不属于上一类 | 仅两个端点盈利，不保证中间或之后持续盈利，也不等于买入前可识别 |
| 短机会后失效 | 前 15m 最大浮盈至少 +20%，但 1h 近似净收益不大于 0 | 曾有报价机会；不是证明能在最高点卖出 |
| 延迟盈利路径 | 6h 至少 +20%，不属于上述类别 | 可能存在晚波段；不证明应一直持有 |
| 普通 / unknown | 不满足上述条件 / 缺乏标签所需覆盖 | unknown 保留，不进行结果填补 |

TEST 主 landmark 的描述性类别（包括此前 1,200 中落在此区的币，仅用于分类清单）：两端盈利 405、短机会后失效 2,064、上涨后急跌 283、延迟盈利 269、普通 7,954、unknown 3,528。这里的分母是具有合格主 landmark 的币，不能除以全档案数后宣称全市场发生率。283 与下表剔除旧样本后的 280 是不同口径。

实际案例图保存在 `data/research/lifecycle_20260908/case_paths.html` 和 `case_paths.png`。按已保存案例文件的每类首例选择，另附已核验报价异常，共四个原始 Token，>30秒缺口不连线。第一例 `1219vjf4jUQ2XNZL6uxSsV9iYpS3XwzigKHELFkqfn1n` 即说明分类的局限：1h与6h端点盈利，但中间约3h曾跌回入场之下，12h又大幅下降。不能把它写成全程稳定上涨或买入后一直持有的答案。固定时点标签必须与持仓过程中的状态判断共同使用。

## 3. 新事实：漂亮上涨不等于值得长拿

剔除旧 1,200 后，TEST 主 landmark：

| 持有终点 | 有效样本 | 近似净收益中位数 | 正收益比例 | 去掉最好单币后的均值 |
|---|---:|---:|---:|---:|
| 15m | 13,909 | -13.73% | 23.29% | -12.06% |
| 1h | 13,387 | -33.36% | 17.82% | -16.43% |
| 6h | 10,795 | -60.23% | 10.22% | -20.29% |

**异常报价足以彻底反转平均值。** Token `7UVZ7KCwnqKCpbxSaauH1jKBd1dZsQSRwauk5Aeu4ok` 的第 2782→2783 行相隔 4.751 秒，价格从 `0.000003248` 变为 `119.97`，约 36,936,576 倍，当时 m5 成交量字段只有 2 USD。缺少池和计价单位 lineage，无法解释成经济收益。它使 TEST 6h 原始平均净收益达到 390.15 倍；去掉这一个币后为 -20.29%。保留原始值和异常证据，不能据此寻找“超级策略”。独立复核直接从两份原始 NPY 重算了时序与净收益公式。

缩尾也不是数据清洗。在 51 个样本的小组内，线性插值 p99 仍会留下这一巨大跳变；分箱研究同时给出中位数、原值和敏感性，不能仅凭一个缩尾均值判断盈利。

| 入场前状态，5m landmark / 6h 结果 | TRAIN 中位数 | VALIDATE 中位数 | TEST 中位数 | 判断 |
|---|---:|---:|---:|---|
| 全部合格币 | -59.13% | -63.91% | -60.23% | 无条件长拿不被这批档案支持 |
| 三段低点与高点均抬升，前涨幅≥6% | -73.36% | -78.94% | -77.32% | 阶梯上涨不能单独作为续持理由 |
| 回撤后恢复 | -73.11% | -77.09% | -77.63% | 修复形态本身不保证后续延续 |
| 买笔数占比≥80%、m5不足20笔、涨幅≥6% | -21.61% | -21.15% | -18.88% | 部分期均值好看，但 TEST 缩尾均值 -17.79%，不稳定 |

近单调上涨定义为：5m 涨幅≥20%、路径效率≥0.9，至少三次实际价格变化，其中正向比例≥80%。初稿把大量未变报价也放进方向比例，覆盖为零；修订为非平价变动比例，保留两版产物。这个修订说明**采样频率不等于价格更新频率**，未变报价不能算成新买盘确认。

近单调上涨 TRAIN/VALIDATE/TEST 的 6h 急跌数分别 7/179、14/150、21/144；TEST 急跌率 14.58%，总体为 280/10,795=2.59%。粗按入场前涨幅分箱后，TEST 的 20–50%、50–100%、100%+ 箱仍有 8.51%、19.57%、15.69% 急跌，同箱非近单调对照为 5.21%、2.91%、2.07%。但 TRAIN 的 20–50% 箱方向相反，样本稀少，收益异常仍存在，**不能声称普遍因果或直接做通用禁买规则**。详见 `gain_stratification.py/json/md`。

这批证据更支持的研究顺序是：买前识别“假平稳、低成交推动、持续上涨但风险增加”；买后观察是否出现真正的新脉冲、成本能否尽快覆盖、支撑失效后能否恢复；用实际下一报价退出，与继续持有进行同币配对。

## 4. 外部研究与 Chat 评审

2026-09-08 核验的原始研究：[USENIX 的 A Midsummer Meme’s Dream](https://www.usenix.org/conference/usenixsecurity26/presentation/mongardini) 讨论低交易量引起的池价格膨胀和后续获利退出；[SolRugDetector](https://arxiv.org/abs/2603.24625) 使用链上交易与状态证据研究 Solana Rug；[SolRPDS](https://arxiv.org/abs/2504.07132) 包含流动性添加、移除与停用信息。这些研究支持把报价上涨、实际流动性和控制者行为分开核验，不把其分类器性能移植成我们的已验证能力。

[DexScreener 官方 API](https://docs.dexscreener.com/api/reference) 提供池价格、流动性、笔数等字段，但不保证每次响应都代表刚发生的链上交易，也不提供未来撤池意图。当前免费行情可支持下述小窗口机制；精确钱包关联、控制权和撤池标签仍有数据缺口。本轮不绕过公共限流、不增加逐币外部 Agent 调用。

已通过现有指定 Chat 路由完成一次实质评审，消息 `C2C-20260908-LIFECYCLE-RESEARCH-01`；它建议到期续持、健康回撤、成本覆盖时钟、部分退出后新脉冲、单调上涨危险对照。采纳同入场持仓配对、有限续持和成本/资金对照；与已有 response exhaustion、partial requalification 重复的方向不再新建策略。Chat 意见只是设计来源；本报告的样本数、代码和核账均来自本地实际证据。

## 5. 六个新运行臂：一个基线、五种不同持仓机制

共同条件：独立新增账户，单次正式 Paper 本金 5U，最多 4 仓。新池年龄 0–15 分钟、m5 至少 3 笔、价格为正、原池流动性不低于实际共享设置；新观测必须在本策略激活后，四个时间按因果顺序且≤15秒新鲜，独立 provider 可识别。通过信号后需下一原池报价，换源或超过30秒失效。身份与原池有效性仍由共享路径强制检查。

这是刻意相同的宽入场条件，便于判断持仓管理是否有效，不宣称该宽入场本身有 Alpha。六臂使用 `lifecycle_same_fill_v1` 配对，在资金或仓位允许共同入场时共享来源 fill；后续持仓占用不同会使可入场覆盖分化，不能拿未匹配账户总 PnL 直接排名。

所有正式臂继承统一硬止损、盈利后跟踪止损、原池流动性底线与实际执行设置；不把过期/缺失报价当作可卖或归零，不回填高点，不自动 Live。各新增状态只保存≤25个独立点、≤2个确认支撑及少量标量；每帧本地常数有界计算，无新数据库表、轮询源或 Agent。

| 新 ID | 核心假设、行为 | 退出与风控 | 主要反证 / 成本敏感性 |
|---|---|---|---|
| `lifecycle_baseline_v1` | 同一宽入场的 5U 基线；用于辨别其余机制是否真的改变结果 | 30m 到期，共享止损/跟踪退出；不加减仓 | 基线本身可能持续亏损；它是对照，不单独宣传为新 Alpha |
| `lifecycle_renewal_v1` | 30m 到期时，只有两次确认低点抬升、新报价突破当前窗口、近低点不陈旧、近似净利≥10%、流动性保留≥85%，才获一次续期 | 不满足即触发退出；续期最长到入场后120m，途中共享风险退出仍优先 | 适合持续双向交易后再次推进；假突破、报价异常、趋势衰减会失败。观察同fill比基线多赚还是多亏及额外资金占用 |
| `lifecycle_failed_rebound_v1` | 盈利阶段跌破已确认支撑，冻结破位价；等待一次未收复支撑的反弹，再破低退出 | 需依次“破位→反弹→再失败”，收复支撑取消；30m上限、共享硬退出 | 避免把正常回撤当失败；直接坍塌来不及等反弹，仍靠共享硬退出。适合脉冲衰竭；观察少损与过早退出的取舍 |
| `lifecycle_giveback_area_v1` | 已知峰值净利≥30%后，累计回吐幅度×实际持续时间，超过6 fraction-seconds退出；新的高点清零 | 使用上一已知状态做左端积分，不能把当前下降套到过去；缺失/换源/边界/长间隙重置面积及高点；30m上限 | 识别多次耗损而非单点最大回撤，区别于已有单次净利回撤策略。慢整理可能被误退；必须配对看右尾保留和额外周转成本 |
| `lifecycle_risk_trim_v1` | 入场120–135秒的唯一检查：还未覆盖成本，且价格、笔数均低于至少60秒前，减少75%持仓，保留25%尾仓 | 请求后用下一有效原池报价实际执行部分卖出；过时不补做、不重复；剩余持仓继承原退出 | 适合早期失去推动力，晚启动者会被减小。固定费用对小尾仓敏感；比较每10U预算收益、亏损尾部和现金释放 |
| `lifecycle_probe_v1` | 正式5U盈利≥10%后，四个独立点出现回撤、修复、超过旧高3%的新脉冲且流动性保留≥85%，再观察一个报价才追加5U Shadow腿 | 仅前10m可取得资格；资格后≤30秒下一同源同池报价成交；独立Shadow预算/手续费/退出账，正式数量和PnL不变 | 不是亏损摊平。适合有资金支持的新波段，假修复会增加损失。**新增腿仍是Shadow，不能把它写成正式加仓收益** |

持仓机制用观察得到的当前支撑、峰值、经济净值、滚动笔数与流动性；没有使用历史类别、未来最大涨幅或后来识别的“好币”。成交笔数和流动性变化仅为可实时获取的近似特征，不称净流入或钱包增持。

预计交易频率：共同入场属于高召回实验，但自然频率未知，取决于新池覆盖、资金、原池新鲜度和四仓上限；最多六臂配对跟随同一个候选，不能把复制成交当六个独立发现。续持、失败反弹、面积、减仓、加仓触发率均须部署后统计，未编造每日笔数。资源上限为6×4正式仓，新增Shadow腿复用同一原池行情。

验证时至少报告：同 token / source entry fill 配对差值、未能配对原因、资金占用时间、每固定预算净收益、每笔真实模拟费用、固定期限后续路径、触发前后数据缺口、最佳单币剔除与日期分区。不同规模不能用单笔绝对利润直接排名；只有自然前向、足够独立Token与日期覆盖后，才能讨论放大仓位。
