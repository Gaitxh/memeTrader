# 2026-09-12 全面审查第 7 轮：把「系统收益最高的入场机制」重建进新增家族（wave 14）

## 1. 为什么选它：全库最强臂的入场判据

`resource_age_rate_candidate_v1`（+634.96U / 221 笔）、`age_rate_horizon_fast_v1`（+109.91U / 75 笔）共用同一冻结入场 `resource_age_rate`（`resource_bound_research.py`）：

- 池龄 **900 < age < 21600** 秒；
- 5 分钟成交笔数 ≥8 或成交额 ≥1000U；
- `old_rate = max( 成交笔数 ÷ (前一小时笔数/11), 成交额 ÷ (前一小时成交额/11) )`，并按实际池龄折算 `adjusted_rate = old_rate × min(55, age/60-5)/55`；
- 要求 `old_rate ≥ 3` **且** `adjusted_rate ≥ 3`。

即：**池龄 15 分钟–6 小时，且当前 5 分钟活动率 ≥ 其自身按龄归一小时率的 3 倍**。该机制至今仍在 pattern 通道运行（本轮复核 +634.96U、1 仓在持），但它与新增家族使用不同的引擎与退出合同，因此此前无法与"实测最强退出画像/存活带/宽度"组合。

## 4. 修复后队列的归因（本轮新增分析）

对 20:21Z 之后开仓、已平仓的 134 笔（**0 写销**、合计 −14.84U）：

| 追踪退出 | 15 | **+0.417U** | +6.25U |

**关键观察**：这些新臂的仓位是 1–2U，硬止损单笔 −0.706U ≈ **−35% 的名义仓位**，而合同写的是 −20%。差额来自**两段式退出的结算方式**（触发用一帧、结算用下一帧的报价），即**止损在结算时又滑了一段**。这解释了为什么"修复后零写销"仍未转正：死亡尾部被消除了，但**普通止损的结算滑点成为新的主要亏损源**。
