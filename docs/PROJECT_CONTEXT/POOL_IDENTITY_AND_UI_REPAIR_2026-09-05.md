# 入场池绑定、账户展示与采样曲线修复

记录时间：2026-09-05。范围：当前独立 1000U Paper 账期；不重新初始化、不删除历史、不启用 Live。

## 已定位的问题

1. **系统缺陷：跨池估值和成交。** DexScreener 的同 token 返回可能包含多个池。原采集按最高流动性选池，退出虽然比较触发前后两帧，却没有核对入场池。当前账期成交 371492、cohort 8918 以另一池价格记入回款 408.0661967514557U、已实现收益 388.0661967514557U，不能视为有效策略盈利。
2. **资金路径污染。** 固定 1000U 下，错误回款可能资助后续本来无钱买入的机会。只减掉虚假收益不足以清理评估口径；必须在受影响策略内按原时间序列重放现金门，并保留、隔离受影响的后续记录。
3. **展示缺陷。** 累计曲线有后端与浏览器双重尾部截取；账户价值未明确展示余额加持仓；发现页缺少独立刷新与分链查询，compact 数据漏掉入场决定计数。旧最大回撤使用已实现闭仓序列，不是包含持仓估值的账户曲线。

## 最小修复

- 同一个 30-token HTTP 响应保留全部池；按持仓原入场池生成共享 mark，退出和估值只使用这一池，不增加按策略重复请求。缺少原池为未知或原池缺失，禁止替换成另一个流动性最高的池。
- 原池两次成功响应均缺失且持续超过 60 秒才核销；网络错误不当作结构性缺失。新鲜原池流动性小于 1U 按剩余仓位全损。
- 保留原始成交，通过已有 append-only correction 撤销无证据回款，并隔离资金门重放识别的污染后续样本；不补造反事实买卖。
- Web 当前价值从同一读事务的有效现金流和原池持仓价值计算，缺少有效估值不显示假 0。余额、持仓价值、总价值分别展示。
- 全账期曲线首次读取后按 snapshot ID 增量更新；每策略内部最多约 600 点、列表最多 32 点、详情最多 300 点，保留首末时间和分桶极值。最大回撤使用采样之前的有效账户快照计算，不由简化图线反推。污染区间保留为空白，不能连接成虚构收益。
- 发现页独立 5 秒缓存接口，支持 ALL / Solana / BSC / Robinhood；单链先筛选再取最近记录。漏斗是当前账期策略决定次数，不是去重 token 数或同一漏斗队列。多链采集轮次包含共享计数，不能称该单链独占计数。
- 账户总价值、余额、PNL、已实现/未实现、回撤、期望、盈利因子、尾部、完成数、胜率、开放仓、前向时长和编号可分别排序。
