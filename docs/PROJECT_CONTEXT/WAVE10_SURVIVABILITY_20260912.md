### 1.3 对本家族的诊断
wave 1–9 的多数机制**刻意选择年轻池**（`pool_age ≤ 600/900/120` 秒）与**低 FDV/深度**（`≤0.7/0.8`）——正是上述 44%–54% 写销的死亡单元格。这与第 2 轮测到的"alpha149 家族亏损主要来自写销（28 笔 −80.0U）而非止损"完全一致，也解释了为什么"金狗画像"（早期深池）在**个例复盘**里成立、在**4.1 万笔统计**里却是最危险的入场区。

## 4. 诚实边界

1. 分组统计来自**已持仓样本**（策略已做的选择），因此写销率绝对值带有选择偏差；但分带内的**相对**差异（44.1% vs 1.9%）在三条链上一致，且分带变量在入场前即可得，仍可直接用于前向实验。
2. 存活带是"少死"，不等于"多赚"：最佳单元格单笔均值仅 +0.497U，必须与退出机制配合；这正是三条同入场臂的设计目的。
3. 深度衰减早退是**假设**（未做历史反事实检验——历史里没有"如果早退会怎样"的价路关联），只能靠同入场对照臂的前向数据检验。
4. wave 10 的自然样本在加载后仅 2.5 分钟，尚无成交，不做任何结论。
