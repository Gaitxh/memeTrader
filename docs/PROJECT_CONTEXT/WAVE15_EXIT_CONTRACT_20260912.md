## 1. 量化：止损实际落在哪里

对最近 7 天 **12,773 笔已结算的硬止损**，逐笔与**该臂自己的** `hard_stop_return` 对比：

| 指标 | 数值 |
|---|---|
| 结算价 ÷ 触发价（两段式结算的缺口） | p50 **0.00%**、p75 0.00%、p90 +21%（**无系统性结算滑点**） |
| 触发到结算的时延 | p25 1.1s / p50 **1.5s** / p90 3.5s |
| **实际亏损 − 阈值（越深为负）** | p25 −21.7 / **p50 −6.4** / p75 −1.5 个点 |
| 比阈值更深的比例 | **87.4%** |
| 深 >10 个点的比例 | 39.0% |
| 深 >20 个点的比例 | **26.1%** |

按阈值分组：−20% 止损的越深中位 **−5.6** 个点（p25 −17.2）；−35% 止损中位 **−14.9** 个点。
最深的臂（`failed_continuation_profit_lock*`）中位越深 **−80** 个点；最贴近阈值的臂（`finalist_seller_absorption_v1`、`dynamic_principal_recovery_runner_v2` 等）中位仅 −1.2 ~ −2.0 个点。

**结论修正**：第 7 轮把差额归因于"两段式结算滑点"是**错的**——结算价与触发价相同（缺口 0.00%）。真实原因是**帧与帧之间的跳空风险**：止损不是一个价位，而是"价位 + 跳到下一帧之前的跌幅"。这解释了为什么写了 −20% 的合同，实际经常落在 −26% 甚至 −40%。
