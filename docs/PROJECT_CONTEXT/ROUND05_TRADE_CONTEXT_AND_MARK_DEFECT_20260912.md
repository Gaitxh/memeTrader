## 4. 根因缺陷：尘埃报价（dust print）可以把深度盈利单打成 −100%

### 4.1 证据（真实前向，非假设）

标的 `solana:Xxd7AzFSJK7xGf68fimagKnNVY2TLfanvn4veEYpump`（池 `ERLQGEGwxwf3aSkSSn3JiHuuwpv1CnwHERsXipca9ngv`）：

| 时间（UTC） | 标记价 | 池深度 |
|---|---|---|
| 00:25:07 | 0.02747 | 443,808 |
| 00:29:35 | 0.02922 | 457,798 |
| **00:30:43** | **0.02963**（= 入场价 4.84 倍，**+384%**） | 461,061 |
| **00:30:54.788** | **0.00000192**（比上一帧低 15,400 倍） | **1,943** |

- 该池共 1,040 条标记，**只有这 1 条**低于 0.0001；
- 多个臂（`alpha149_merged_multi_setup_v1`、`survive_noise_wide_v1`、`vol_scaled_merged_v1`、
  `survivable_deep_v1` 等）**在 00:30:54 这一帧被判为追踪/止损退出**，成交后 `amount_raw=0`、
  已实现 **−1.999U / 2U 本金 = −100%**——即"峰值 +384% 的赢家被一条尘埃报价清零"。

**量化该缺陷的发生频率**：近 60 分钟 2,093 条标记中，有 **6 条**同时满足
"价格 ≤ 前 5 条均值的 10% 且深度 ≤ 前 5 条均值的 25%"（约 **144 条/天**），每条都可能污染一次退出判定。

### 4.2 修复（`store._mark_is_plausible`，缺陷修复而非策略改动）

- 在**价格驱动退出**（`HARD_STOP`、`TRAILING_EXIT`、`TAKE_PROFIT_*`）成交前校验该标记：
  取同池最近 5 条 `VISIBLE` 标记的中位价与中位深度；仅当
  **价格 ≤ 中位价 ×10% 且 深度 ≤ 中位深度 ×25%** 时判定为尘埃报价并**跳过该帧**（不计入退出），
  同时计数（每 25 次写一次 `kv['mark-outlier-vetos']` 供审计）。
- **不拦截**流动性退出与写销：真正枯竭的池子仍必须离场（`LIQUIDITY_EXIT`、
  `dex_pool_liquidity_below_configured_floor_writeoff` 路径完全不变）。
- 参照不足 3 条、价格缺失或非法时**不做判断**（fail-open，保持原行为）。

### 4.3 验证

- 新增 `tests/test_mark_outlier_guard.py`（2 项）：
  ① 尘埃报价（1,943 深度 vs 45 万池）**不得**平掉任何仓位，且守卫计数 >0；随后真实崩塌（−25%、
  深度仍在 38 万）**必须**照常退出；
  ② 缺少参照或输入非法时守卫**不做判断**（fail-open）。
- 相关测试集 **98 项全通过**（alpha149 / wave24-26 / score149 / participant_flow / dex_trajectory /
  shared_batch148 / whipsaw / mark-outlier）。
- 已重载部署（PID 16820/10152）；冻结错误 `#265=392`、`#266=398` 未增长，最新错误 id 275（无新类型）；
