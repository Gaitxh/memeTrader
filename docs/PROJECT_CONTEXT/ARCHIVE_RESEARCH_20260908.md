# 8万币档案研究、独立Paper实验与全链路验收（2026-09-08）

## 裁决

本轮没有发现可宣布为Alpha的证据。历史筛查显示，单靠短时上涨、活跃或表面买方占优，不能推导成本后持续盈利。新增三个小额Paper账户，用当前系统可取得的原池、严格时间及成本数据，证伪两个新入场机制和一个配对退出机制。它们不是从历史胜者回填，也不是已通过历史收益门槛的策略。

完成两项有明确瓶颈依据的速度修复：新来源证明唤醒无池补全、每轮各链分别批量刷新候选。详细运行对比见 [SPEED_COVERAGE_20260908.md](SPEED_COVERAGE_20260908.md)。

### 新发现与反证

- 较晚日期188个合格币中，29个在30分钟内曾有至少50%的毛价格上行，其中11个到30分钟的假设滑点后标签仍亏损。MFE只用于结果诊断，不能作为入场/预知峰值特征。这说明退出研究有意义，但不证明能及时卖到高点。
- 八个描述组都没有稳定的跨时段正期望证据。低活动/高路径效率组在留出期仅5币，均值−30.33%；样本不足且反证明显，不能宣称低活跃就是机会。前240秒高波动、最近60秒上涨组，在发现期均值+0.96%，剔除最佳币即−10.01%，验证期−37.37%、留出期−19.94%。单一大币能制造表面优势。
- “高波动后涨价”与“高活动停滞后释放”是不同定义；本档案筛查只实现前者，不能冒充后者。近峰平台描述组也只是未来结果分组，不是持仓退出对照实验。
- 两个实际留出档案已独立核对原始行号和滑点算式：`9q5bvzXkZwXBTLrKoPCfqGQUm7vBaaayngpZoKDvpump`（2026-05-26）30分钟标签+415.48%；`88PTS8QBtN6hS3PftdAtF597w5p1sGFMfxqNN5bWqpNx`（2026-05-21）−99.92%。后者是档案价格崩落，未验证Rug、池切换或真实可卖性。禁止按已知结果将前者回填为策略成功交易。

首轮脚本存在行号窗口、状态命名和标签时效错误，已作废保留；之后中间稿仍有活动比值未归一与命名不准确问题。最终有效工件仅 `run_empirical_final.py`、`samples_final.jsonl`、`empirical_final.json`、`root_numeric_checks.json`。不沿用旧稿样本量、收益数字或Chat/子代理建议作为事实。

## 新增策略合同

共同约束：独立新增ID/账户，普通5U买入、最多4仓；每个账户自己的1000U起始资金和启用前沿，不初始化任何旧账户。仅观察启用后新数据，最新帧15秒内、同Token/原池/来源、中间间隔≤30秒；6个独立15秒样本。完整1小时统计仅在池龄1小时至24小时使用；负数或h1小于m5的嵌套统计拒绝使用。流动性执行下限取用户当前设置，默认1000USD。

`A = 11 × m5交易笔数 / (h1笔数 − m5笔数)` 是每分钟活动率的代理；`E = Σlog价格变化 / Σ|log价格变化|` 为实际采样路径效率。它们都不是独立钱包、真实买入资金或链上净流。

|---|---|---|---|
|archive_drift_v1：低参与高效率漂移|6帧价格净升6%—25%、E≥0.75，最近3帧A<1且买入笔数占比≥55%；随后同来源新鲜报价才成交|30分钟上限、−20%硬止损、收益30%后回撤15%追踪、无固定止盈；测试活跃降温但价格仍有效推进|盈利来源假设为低冲突的持续推进；档案描述组负且稀疏，不支持Alpha。可能无量诱多、滑点吞噬小涨、突发流动性撤离|
|archive_plateau_v1：漂移与拥挤平台退出|与上一臂完全相同入场，同一fill配对，仅两者均有资金/名额才开仓|共同退出之外，成本后价值盈利≥10%，6个至少5秒间隔原池帧处于已知峰值2%内、价带≤1.5%、绝对E≤0.25、m5笔数增≥30%、买入笔数占比未提高，触发全退；下一报价结算|假设拥挤却无价格进展是衰退前兆；可能提前卖掉健康换手后的第二段上涨。缺失/失败、来源变化或>30秒间隔重建平台序列；采样间的新高仍记录，禁止未来峰值|
|archive_release_v1：高活动停滞后效率释放|前三帧价带≤4%、A≥2；后三帧A≥1.5且正向E≥0.6，末价突破旧段高点6%、买入笔数占比较旧段平均高10个百分点；再等次报价|与漂移基线共同退出；用于活动先拥挤、价格后出现方向的状态|区别于单纯追量/追波动和卖方多数翻转；真实金额与钱包未知，可能wash activity、假突破或刚好买在冲顶。档案高波动描述组不是本机制验证|

交易频率：尚无足够自然前向数据估计每日次数；每个币/原池按既有一次入场约束，最多4个同时仓位/臂。观察器总候选容量仍为既有30个非持仓币及共享持仓，频率不是全市场扫描保证。新增策略不新增网络请求或后台Agent；只消费已有帧，退出窗口最多6个状态记录。

成本敏感性：默认平价往返损失约7.69%，需要价格上涨约8.33%才覆盖两侧4%滑点，额外费会进一步提高门槛。小额Paper结果为模拟，不代表未来Live可实现。共同资金/执行/记账/失败恢复逻辑保持；没有放宽因果和原池标准来制造交易。

### 如何判定假设失败

用未来新增独立Token/日期块，不以多账户复制算样本。观察所有入场拒绝原因、实际填单价格、净PnL/持仓时长/最大回撤/尾损、成本敏感性与去最佳币结果；漂移基线和平台退出按相同fill比较净差、尾部保留和提前卖出后的已记录路径。活动率不同/缺字段群体分开，不能强补零。30个独立完成Token之前仅报告覆盖和个案；之后仍需至少3个日期块、去最佳币及配对净差共同支持，才值得继续讨论规模，未满足不宣称盈利机制。没有自动转Live或定时部署。
