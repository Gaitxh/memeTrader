## 187 语义纠正

`trailing_activate_return=0.0` 的真实含义是：running economic return 先达到成本后保本，再启用 15% trailing。它不是“从入场即启用”。在双边各 4% 滑点下，首次可卖净值通常低于成本，需要标价先上涨约 8.33% 才达到保本。已运行合同不改写；源码、测试、报告和记忆改为 `break-even armed`。只有共享 marks 证明净峰值位于约 -5.88% 至 0 的相关路径频繁出现，才考虑独立新 frontier 的 first-valid-mark 实验。

## 固定前向成熟门

1. trajectory187 按链、共同 source fill 和 Token 聚类配对，至少 30 个独立成熟配对 Token，覆盖至少两个日期。
2. 入场后的共同观察窗口至少覆盖最长 120 分钟；open、失联和缺失结果必须单列，不能只挑已闭仓。
3. 报告成本后净收益、配对差、核销、最大赢家占比，并给出删去最大赢家后的结果。
4. 未达到门槛保持 `INSUFFICIENT`；达到明确负期望门则暂停新入场、已有仓位继续退出。
5. 不以每日最好结果增加参数臂；当前三臂足以检验分链快慢退出与保本后 trailing。
