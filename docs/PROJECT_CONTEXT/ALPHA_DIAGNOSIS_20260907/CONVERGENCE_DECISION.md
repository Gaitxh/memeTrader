2. **是否只是观测选择？** 保留所有既有候选/拒绝/资金不足/缺帧分母，按同观察合同比较完整率。当前覆盖负控没有强线性预测力，但BUY/非BUY完整率不同；不能用“负控未显著”认证无偏。
3. **退出是否创造增量？** 仅同实际Entry/数量/成本与共同评价时点比较progress/giveback，保留开放和未知结果。若持续没有经济分离，停止扩大暴露；若优势集中于极少Token，只降低置信度，不机械删除右尾来筛策略。
