# Alpha诊断：证据没有支持继续扩张

冻结数据截至 **2026-09-07 13:38:59.399800 UTC**。最终类别 **E：独立、同质且可观察的证据不足**。这不是证明Meme市场没有alpha，也不是证明现有特征完全无信息。本轮新增策略 **0**，没有实施Court的冻结/退役建议，没有改生产、重启、初始化、调低成本或进入Live。

当前230个账户没有形成稳定盈利，已观察到的解释是：大量账户重复暴露于同一批Token；亏损和Paper核销较多；正收益高度集中在少数Token；新增Gate/Exit的修复后边际值很小或方向反转；有统计排序线索但最高分组尚未稳定得到正的成本后收益。**这些事实不能分解成唯一的因果亏损配方。** 特别是不能把所有全损归因Rug、把所有负收益归因延迟，或把历史混期正PnL当稳定优势。

## Q1：当前特征能预测超过成本门槛的移动吗？

**有局部统计线索，尚未证明可交易正期望。** 6064个修复后机会来自93个Token，6041个严格receipt机会仅82个Token；6058共享receipt不等于6058账户成交，实际账户BUY机会404个。正式预测锚为源快照recorded_at，不冒充原策略真实决策时间。总体是当前observer选择、receipt可恢复且有后续原池行情的条件子总体。

固定L0特征、Logistic与深度3树，无调参搜索；训练标签先成熟、按时间前推且训练/测试Token隔离。主要15m标签为首次盈利阈值后严格新观察帧是否仍盈利，固定15m收益另作对照；30/60m仅敏感性。完整方法与逐模型结果见 [ENTRY_EDGE_DETECTABILITY.md](ENTRY_EDGE_DETECTABILITY.md)。

## Q3：230策略压缩成多少真正不同的家族？

**152个映射后的经济指纹家族**，另有148个声明合同组、171个合同+dispatch精确组、102个入场dispatch组、84个退出组。152不是152个已证实独立alpha机制。实际共同机会完整成交路径确认59个重复账户可建议退役；14个无BUY账户只能标覆盖/触发未知。详见 [FAMILIES_METHOD.md](FAMILIES_METHOD.md)、[STRATEGY_BEHAVIOR_FAMILIES.csv](STRATEGY_BEHAVIOR_FAMILIES.csv)。

## Q4：哪些Gate有正边际价值？

本轮没有Gate被证明在当前修复后窗口稳定创造正边际值。Chase从持久化拒绝receipt恢复共同分母：35个机会中13个拒绝，避免亏损19.39U，但错过盈利30.25U，净效应 **−10.87U**；Token均值区间[−2.0060,+0.8196]U。更早196个共同机会净效应+50.33U，方向相反，不能混期宣布有效。

资金不足、slots不足是账户准入，不是alpha Gate反证；其他Gate缺完整共同拒绝分母不能作零价值结论。详见 [GATE_MARGINAL_VALUE.md](GATE_MARGINAL_VALUE.md)。

## Q5：哪些Exit在同Entry上改善？

修复后同实际入场的35个终结Token：progress_clock净改善 **+9.10U**，giveback_duration **+1.16U**，profit_budget **−1.78U**。前两者Token均值95%区间均跨0；多组规则虽有内部状态变化，却没有经济差异。不存在“已证明Entry有edge，只是Exit毁掉它”的证据。配对终结交集仍可能遗漏开放仓，不能泛化为完整组合值。

保留progress/giveback作为两个 **PROMISING_UNPROVEN观察候选**，不认证alpha、不加账户、不从历史挑最佳退出回放。详见 [EXIT_MECHANISM_VALUE.md](EXIT_MECHANISM_VALUE.md)。

## Q6：数据与延迟是否吞掉优势？

当前7435个Token/cohort机会，源可用时刻代理→验证v6 receipt的延迟p50/p90 **13.089/23.662秒**；修复后429个机会 **15.022/44.164秒**。7424个非晚源时钟有效机会的市场漂移p50为0、p90为+5.5681%，买侧4%摩擦单列。11个晚源时钟记录排除因果有效子集。

成本合同平价往返损失约7.69%，市场需涨约8.33%才覆盖4%/4%不利价格。漂移和滑点不能直接相加当因果损失。延迟桶收益没有稳定单调衰减，而且缺完整真实decision时刻与可实现更快反事实；**不能断言延迟已经吞掉原本存在的edge**。详见 [DATA_LATENCY_EDGE_DECAY.md](DATA_LATENCY_EDGE_DECAY.md)。

## Q7：下一步投入哪里？

最可靠的行动结论是 **停止增加策略名字，先收敛重复暴露与证据分母**。这不是已证明“改数据的盈利ROI最高”。当前无法可靠排序Entry、Exit、Data、latency或universe改动的真实收益。

研究优先级：用既有采集/拒绝记录让同机会、未成交与覆盖缺失可比较；用少量现有行为不同的基准继续获取新的日期与Token证据；对progress/giveback保持同Entry比较。不得通过降成本、放宽因果边界、扩新源或自动新增策略制造好结果。外部发现首先作为输入可用性假设，而非买入许可，见 [EXTERNAL_EDGE_DATA_GAP.md](EXTERNAL_EDGE_DATA_GAP.md)。
