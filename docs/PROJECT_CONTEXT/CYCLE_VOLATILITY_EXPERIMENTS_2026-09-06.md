# 两组独立机制实验：深重置二波与波动率归一化动量

## 问题与证据边界

原184策略已覆盖普通静默突破、浅回踩、止损收复和依赖先前平仓的Wave Reset。本次不复制这些策略：新增观察到完整首波/深重置但不要求曾持仓的二波实验，以及相对本池历史噪声的短时动量实验。旧策略规则保持不变。

pre-VOID漏斗只证明哪些分支有输入、信号或覆盖，不用于证明收益；573笔VOID及371笔资金依赖BUY不作为策略经济有效性依据。两组均是有输入能力和行为差异的可检验假设，不宣称盈利。

## 冻结规则（参数同时记录在policy.entry_filter）

四个独立ID：

- `observed_cycle_reset_reacceleration_v1`
- `observed_cycle_reset_reacceleration_control_v1`
- `volatility_scaled_depth_flow_momentum_v1`
- `volatility_scaled_depth_flow_momentum_control_v1`

共同条件：只用各自部署后、同Token同原池、观察/入库/决策顺序正确的帧；独立帧间隔至少15秒、连续间隔不超过90秒，当前帧年龄不超过30秒。直接复用现有最近20分钟/最多80帧有界历史。信号只产生意图；下一份独立同池且不晚于60秒的有效报价才成交。原池新鲜价值低于1U的禁止买入/剩余全损规则保留。各账户1000U，单笔5U，现金不足不买；同金额共享采集/成交证据，但现金、仓位与退出独立。

### A：观察到首波后的深重置二次启动

至少16帧、跨度12分钟，池龄至少30分钟。触发前300–60秒的底部至少6帧且跨度至少180秒，最高/最低价不超过1.08。当前价为底部中位数1.12–1.35倍，5分钟成交额至少底部中位数1.5倍，流动性至少保留80%，买入笔数占比至少60%，总笔数至少6。

候选额外要求：底部之前实际记录的峰值距当前6–15分钟、相对峰前低价上涨至少35%；峰后到基底起点的谷底为峰值50–75%；底部成交额中位数不超过峰值附近三帧中位数的50%；当前仍不超过旧峰90%。先峰、后谷、再基底、后触发，不能用事后ATH或跨缺口推定沉寂。

对照仅删除首波/深回撤/首峰成交额对比条件，保持相同底部与当前触发条件。二者不是强制同入场对照；对比覆盖及后续相同退出的表现。

### B：波动率归一化资金压力动量

最近9帧跨度2–10分钟，池龄15分钟至6小时。前7帧的6个log return按各自时间间隔平方根归一化；稳健波动率为1.4826×MAD，并设0.005尺度下限。末两段价格涨幅4–25%，用该基线波动率及触发跨度标准化后至少2。

末两帧买入笔数占比至少60%，末帧总笔数至少8。末三帧最低流动性不低于前七帧中位数85%。压力代理量为 `(2×买入笔数占比−1)×5分钟成交额/流动性`：末两帧为正、不下降，末值至少0.02。这不是实际净资金流、独立钱包数或订单簿OFI，也不用于数量冲击精算。

对照以固定8%触发阈值替换动态标准化门，其余条件不变。假设是动态尺度能区分相对安静与噪声很高的市场，而不是小改止损参数。

## 退出和执行

完全复用现有 `pattern_cost_scaleout`：按现有成本口径-20%止损、+30%卖剩余50%、+80%清仓；+30%后15%回撤跟踪，最长15分钟。双侧4%和原池前后确认不变，不扩大普通Paper深度报价依赖，模拟回款不保证真实可兑现。账户独立，不使用带20U固定配对资金门的 `paired_entry_group`。

## 验证和后续评估

纯信号反例覆盖缺首波、数据间断、未来入库、混池、流动性低于1U；三链真实Store测试覆盖注册幂等、旧定义/activation保留、下一独立帧5U成交及账户隔离。测试还复现并修复了公共缺陷：同池相同/更旧时间戳的重复帧会清空pending信号；现在不重新入库/重算该重复观察，不修改旧规则，不补造过去BUY。

部署后先看近期观察帧→就绪→下一帧判定→余额门→BUY；不能将重复就绪帧当独立机会。累计至少30个独立信号及20个完成生命周期后才进行初步经济比较；不足时只说明覆盖。按实际forward age、链/时间块、净收益中位数、截尾均值、P10/P90、最大回撤、盈利集中度和资金占用比较。该门槛只是避免极小样本结论，不是证明有效的统计保证。研究仍手动触发。

## 外部先验（不等于本项目收益证据）

[Cont等：The Price Impact of Order Book Events](https://arxiv.org/abs/1011.6402)在美股订单簿研究中讨论了流不平衡与深度的关系；本系统只能计算聚合代理，不能把结论直接搬成meme币盈利保证。

[Moskowitz等：Time Series Momentum](https://fairmodel.econ.yale.edu/ec439/mosk.pdf)研究的是流动期货的月度尺度，可用于提出持久性/波动率尺度假设，不支持分钟级meme策略已有盈利能力的结论。
