## 2. 市场宽度实测（wave 12 的校准依据）

对最近 20 分钟 21,771 个代币、140,189 帧的横截面统计：**每一分钟"最新一帧高于上一帧"的池占比**，中位仅 **13.3%**（p25 10.4%、p75 17.1%、最大 37.8%）。
→ 绝对阈值型"市场转好"门槛（如 ≥50%）在本市场**永远不会触发**；必须用**相对改善**。

## 3. 新增策略（wave 12，3 条全新 ID，既有策略零改动）

新增引擎内**因果宽度度量**（只用已接受的帧，无新请求、无前视）：
- `fast` = 最近 40 帧上涨占比；`slow` = 全程（≤400 帧）上涨占比；`ratio = fast/slow`。
- 阈值冻结为 `ratio ≥ 1.2` 且 `fast ≥ 0.15`、样本 ≥120 帧；无 regime 输入时一律 False（不推断）。

| 新臂 | 入场 | 退出 |
|---|---|---|
| `alpha149_regime_throttle_revival_v1` | **新机制 `regime_risk_on`**（宽度相对改善） | 实测最强短兑现合同（−20% / 追踪30→15 / 30 分钟） |
| `alpha149_merged_regime_v1` | **新机制 `merged_regime`** = 五形态合并 **且** 宽度改善 | 同上 |
| `alpha149_survivable_regime_v1` | **新机制 `survivable_regime`** = 存活带 **且** 宽度改善 | 同上 |

这是对**已暂停正收益假设** `market_regime_throttle_v1`（+19.62U / 9 笔 / 0 写销）的复活：原臂保持暂停与历史不变，新臂以新 ID 承载同一假设，并额外检验"好池子"与"好时机"是否需要同时满足。

## 5. 诚实边界与下一轮（6/256）
