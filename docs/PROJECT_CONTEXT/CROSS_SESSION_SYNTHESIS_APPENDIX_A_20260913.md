## A.0 一条被推翻的假设（我自己本轮差点犯的错）

**`mover_reserved_admissions = 0` 不是缺陷，机制正常工作。** 我原以为保留名额从未生效，
准备去"修复"。第二个独立测量推翻了这个判断：

| 组 | 每 token 去重帧数（20 分钟） |
|---|---|
| 被标记 mover（24 个，含 2 个持仓 token） | 均值 **29.67** |
| 其中非持仓的 22 个 | ≈ **5.4** |
| **对照：未标记的新发现 token（24 个）** | **1.00** |

`reserved_candidates()` 是**上限**语义（`8 − 已在观察窗内的被标记数`），被标记 token 已占满
名额，故返回空——这是设计意图。**这正是旧 session 第 4 条查询纪律警告的情形（"任何
『0 样本 / 停滞 / 缺陷』结论必须用第二个独立测量确认"），我照做后避免了误改一个正常机制。**
真正的约束是观察窗**容量饱和**（`watched=34` 而槽位 30，`sampled=19`），不是保留逻辑。

## A.1 与我此前结论冲突/收窄的三条

### A.1.1 「策略沉默」的真因是**家族资金墙**，不只是暂停
旧 session 7 天口径 [seq 15918]：**113,696 条拒绝 / 73,609 个 token** 的原因是「匹配到的家族里
没有任何臂能产出 20U」，是第三大拒绝原因；261/442 个臂 24 小时内零开仓；
`dex_visible_successor` 14/14 完全耗尽；68 个臂现金 <20U，其中 34 个同时
`entry_match_mode=NONE`。

**与我的发现合并后的正确表述**：本设备新资金期所有臂都满额（p10 940U），所以"资金耗尽"
在此不成立（WS-D 已证）；但**家族级无可用臂**的判定同时包含"被暂停"和"资金不足"两种原因。
我此前只看到"暂停"这一面。两个口径不矛盾，是同一判定在不同时间尺度上的两个分支。

### A.1.2 同池上限的影子证据**有选择性偏差**——我的裁定依据被削弱
旧 session 明确记录：影子证据从 73.9%/−135U → 74.9%/−335U → **81.1%/−603.35U**，
**但「未被证明（选择性偏差：较晚进入的臂进入更晚、价格更高）」** [seq 14277, 14305]。
且最大单 token 并发实测为 **60 个仓位 = 60 个臂 = 1,200U**，前 12 大 token 全是 60/1,200U，
平均 15.71/token；有实例是 60 个臂在**同一秒、同一信号价 3.01288e-06** 建仓。

**因此我保留上限的理由必须改为主张它的真实价值，而不是那个影子数字：**
- **去相关**：350 个仓位只覆盖 11 个 token 时，整本账只有 ~11 个独立下注，任何策略排序都在
  测「倍数」而不是「策略」。上限让独立 token 数升到 **15**，且每次结算最多 3 个新臂。
- **释放名额**：被拦下的臂保留现金、可参与**其他** token——这正对应用户第一条诉求
  （"绝大多数 token 未能进入"）。
- **不可达/可回滚**：只约束新准入，从不追溯平仓；定义为 `max_arms_per_pool: null` 即恢复原状。
- **诚实标注**：影子证据的选择性偏差是真实的，故**不引用 −3,329.95U 作为省钱证明**。

### A.1.3 旧 session 的刷新节奏（p50 89.8 秒）比我写的「60–120 秒」更慢
旧 session 测得全局刷新 **p50 89.8 秒，仅 17.5% ≤60 秒**；ready 池每小时被评估 6 次；
**ready→准入 损失 95%**（50.6% 间隔 >60 秒、39.6% 从未被重新评估、3.5% 成功）。
我此前的 60–120 秒来自本设备小样本，**应以 89.8 秒 p50 为准**。

## A.2 我此前完全不知道的高价值事实

### A.2.1 ⚠️ 观测预算**投错了深度档**（最高价值的未尝试杠杆）
旧 session [seq 11788, 12035]：
| 首次观测深度 | ≥2× 达成率 | 相对基准 |
|---|---|---|
| **20k–100k** | **19.2%** | **1.75×** |
| 1k–5k | **3.1%** | **0.36×** |
| 基准 | 11.0% | 1.00× |

**而"我们大部分预算花在 1k–5k 档"**。这是一个 **6 倍**的达成率差，且是**可点即改的预算
再分配**（把观测名额从 1k–5k 移向 20k–100k），不改任何策略。
配合池死亡分层（BSC 40.4% vs Solana 3.4%；深度 5k–20k 32.1% vs ≥100k 3.8%），
**深度与链的组合是目前证据最扎实的入场质量维度。**

### A.2.2 161 个仓位被记为 >100× 收益 = **+8,218,961U 虚构盈亏**
全部落在两个**已退役**账期（`v22-…` 9 个 / +7,844,846U，其中一笔 20U 仓位经
`market_mark_zero_5m_activity` 记为 +2,162,979U 且 `amount_raw=0`；`v19-…` 152 个 / +374,115U）。
当前账期干净（最大 +518.2U = 25.9×）。行被保留为证据，由
`paper_execution.plausible_position_pnl`（`IMPLAUSIBLE_PNL_MULTIPLE = 100.0`）排除。
**任何历史账期收益序列在未套用该过滤前不可用。**

### A.2.3 统一 20U 复权会把当前账期亏损放大 1.49×（−129,258U → −192,668U）
探针臂（1U×66、2U×77、5U×121）**低报了 10–20 倍美元损失**，尽管其收益率更差
（1U 组 −28.70% 收益率但仅 −321.8U；20U 组 −24.63% / −111,424.7U）。
**且胜率排序是错的排法**：探针 23–28% vs 20U 组 18.7%。
→ **绝不能用小仓位臂的收益率去挑策略，也不能用胜率排序。**

### A.2.4 真正稀缺的是**标记（marks）**，这解释了为什么退出难以精细化
实测 **15 分钟只有 46 条 mark，而对约 90 个持仓** [seq 9142]。
→ 需要反复评估才能触发的退出（追踪、深度衰减、信号衰减）**大多根本没机会解析**；
**`max_hold`（只需一次评估）在历史上是最大的正收益家族**。
这是"退出层不是亏损来源"的机制性原因之一，也提示：**先解决 mark 供给，再谈复杂退出**。

### A.2.5 一次性的止损过冲机制已被更精确地归因
成交缺口 p50 **0.00%**（他们撤回了"结算滑点"的归因）；真因是**帧间隔**：实际亏损中位数
比自身阈值**深 6.4 个点，87.4% 更深**，且随持有时长恶化（−5.05 → −11.36 点）；
FDV/深度 >20 时中位深 **−65 个点** [seq 4833, 4962]。

### A.2.6 跨来源报价差异可达 **3.7e4 倍**；61.7% 的重复峰值来自非首个来源
配合已记录的镜像陷阱（`strategy-observer:X` 在同一 `observed_at` 复制 `X`，占快照行 64.3%）
——**多来源去重与来源一致性仍是数据层的活跃风险**。

## A.3 明确的**死路清单**（不要重做）

固定 +40% 止盈锁（比不加锁差 −25.4U，同成交对照）· 延后/放宽止损 · 持有更久 ·
**分批止盈阶梯** · 抗洗出宽限/确认止损（−37.6% vs −21.6%）· 换手率过滤 ·
入场买盘占比门 · 提高臂并发以加速实验（单载体帧供给在 2→654→98→131→140→3 间剧烈波动）·
多入场并集载体（`any_band` 就绪数 == `survivable_open_band`，32=32）· 放宽安全带深度下限。

> **对我的 EXIT150 的直接含义**：**「分批止盈阶梯」是被记录的家族级死路。**
> 但旧 session 测的是 **+100%/+200%/+400%** 档（不可达，72 小时零触发），
> 我的是 **+15%/+30%/+55%**（本设备实测 p50 峰值 +22.7%、最大 +55.0%）。
> 这是**针对同一家族"不可达"这一具体失效原因的变体**，不是同一次实验的重复。
> 仍须诚实标注：它属于一个已被证伪的家族，只能用前沿 15928 之后的前向数据评判，
> 且**不得因本轮的小样本而宣称有效**。

## A.4 mark 供给与退出评估的新约束（据此调整下一轮）

退出要精细化，前提是每个持仓能拿到足够的 mark。当前 **46 marks/15min vs ~90 持仓**。
→ 下一轮应先测量并提升 mark 供给（`chain_meme_trader_pool_marks` / `market_marks` 的
写入路径与节流），而不是继续加退出规则。**加规则而没有 mark，等于没加。**
