用前向证据而不是回放结论来决定它是否值得保留。回放本身也承认有 ~128U 的不可建模现实
（死池成交、跳空），所以水平值不可直接当收益预期。

## 4. 外部源停摆根因（2026-09-03T15:00:12Z）——设计内暂停，非缺陷

- 最后一批采集：2026-09-03T15:00:07Z 启动、15:00:12Z 完成，**11 个采集器（9 RSS + 2 Mastodon）全部 `completed`、错误为空**；
  当日 rss 14,525 次、mastodon 2,190 次、reverse_news 782 次。
- 停止原因是运行时**任务表分支**：`runtime.py:9282` 在 `chain_meme_trader_only=true` 时提前返回，
  使用 9308–9430 的链上优先任务表，其中**不包含** `external_sources`（该任务在通用分支 9444 才注册）。
  配置 `strategy_focus.onchain_primary_focus_enabled=true`，与 2026-09-03 的链上优先收敛一致。
- 结论：这是**有意暂停**（同时暂停的还有 KOL：`include_kol=not chain_meme_trader_only`）。
- 影响：用户要求的"社交维度（提及速度/加速度、KOL 提及、情绪）"当前**没有采集来源**；
  链上维度与风控维度不受影响。是否恢复免费 RSS/Mastodon（不含付费 Agent）需要用户决策（见第 8 节）。
