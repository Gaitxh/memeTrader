## 0. 本轮结论：诚实版

1. **第 91 轮的"根因"只对了一半，已加更正横幅。**
   `store.py:29803-29820` 存在一条**与族无关**的匹配通路 `entry_match_mode == 'dex_visible'`
   （激活定义里 14 个），对任意计算族都成立。所以"没有 `market_visible` 策略"**不构成不可逾越的阻断**。

2. **真正的拦截点已收窄到"候选臂集合为空"，但存在一处未解矛盾：**

   | 测量 | 结果 |
   |---|---|
   | 最新 3,000 条被拒记录中 `eligible_historical_policy_count = 0` | **3,000 / 3,000（100%）** |

   | 通过 `min_m5_trades≥3` **且** `min_m5_volume_usd≥200` 的行 | **1,216（40.4%）** |
   | 仅因成交量被拒 / 仅因笔数被拒 | 156（5.2%）/ 1,632（54.4%） |

   **矛盾**：我对一条 `m5_trades=28, m5_volume=$9,243.96, prior55_trades=282, age=17,876s` 的被拒行
   做了**逐策略忠实重放**（`r92e_replay.py`），按 `store.py:29632-29654` 重建输入、
   按 `store.py:24338-24400` 重放过滤器：

   ```
   frontier_excluded 0   forward_disabled 0   mode_excluded 1
   not_matched      98   filter_failed    0   ELIGIBLE      28
   ```

   **应有 28 个策略合格，而该行记录的是 0。**

3. **本轮新查明的重要事实（此前所有轮次都不知道）：**
   我此前一直读的是 `chain_meme_trader_v6_registrations.definition_json`（**原始契约**）。
   运行时用的是 `chain_meme_trader_effective_definition_from_connection`，它叠加了两层：
   - `chain_meme_trader_v6_activations` → 给每个策略补 `forward_activation_snapshot_id` / `forward_started_at`
   - **`chain_meme_trader_policy_additions`：336 行运行时新增**

   **∴ 有效策略是 463 个，不是 127 个。** 这 336 个新增：

   | 项 | 实测 |
   |---|---|
   | 匹配模式 | `isolated_pattern_observer` **119**、`isolated_cohort_observer` **211**、`native_protocol_model` **1**、`exact_entry_family` 4、`None` 1 |
   | **`dex_visible`** | **0** |
   | 族名 | 全为专用名（`alpha149_*`、`dex_*`、`exit150_*`、`recipe145_*`…），**没有一个**是四个可计算族名 |

   这解释了为什么"加了 336 个策略"却没有提高转化：
   **330 / 336 的匹配模式被 `snapshot_policies` 直接排除**（`store.py:29610-29612`），
   剩下的族名又永远不会等于计算族 ⇒ **它们进不了这条入场评估路径**。
   它们走的是各自的 `isolated_*` 观测车道（`observe_chain_meme_pattern`）。

4. **前沿（frontier）不是全局阻断**：`activation_snapshot_id = 0`，所以 127 个基础策略的前沿是 0；

## 1. 未解矛盾的处理方式

**我没有把矛盾"解释掉"。** 两种可能都还开着：

- (a) **重放与真实代码存在偏差**（例如 `snapshot_policies` 在别处被再次收窄、
  `proposed_family` 与 `feasibility` 分支不同）；
- (b) **代码在这些行写入之后改过**（行是历史，代码是现在）。

**判定方法已明确**：把 `enroll_chain_meme_trader_v6` 的这段循环用**真实 Store 实例**在
**一条合成快照**上跑一遍（不是重放，是真调用），看 `eligible_policy_ids` 是否非空。
这能一次区分 (a) 与 (b)。

**在证明之前，不得据第 91 轮建议部署任何东西。**
