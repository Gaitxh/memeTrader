# 发现补全与跨链候选刷新（2026-09-08）

## 已部署的修复

- 新的发现来源证明到达后，若 Token 上一次补全为 `no_pair` 且新证明晚于该尝试，立即重新排入既有补全队列。重复来源、已成功补全和普通请求错误不重置退避。最近500条曝光的核验中，仅1个有新来源的延迟目标满足这一修复条件；不能把其余重复曝光都算作漏采。
- 原形态观察器每15秒一轮，但一轮全局只允许一个候选链请求，三链同时需要刷新时存在跨轮等待。改为每个到期链各一次批量请求；仍最多30个非持仓候选、持仓优先、共享并发/冷却/限频。不增加逐币请求或放宽时间、身份、资金规则。三链全需请求时最多比原先增加8次/分钟。
