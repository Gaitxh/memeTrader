# memeTrader

A small, forward-only event-driven meme-token discovery and paper-trading bot for a personal Windows computer.

The resident process combines public social/news observations with new-token/new-pool discovery. Token-only momentum is watch-only: candidate evaluation requires independently observed social, news, community, or official evidence. Historical cases are isolated tests and never production winner priors.
