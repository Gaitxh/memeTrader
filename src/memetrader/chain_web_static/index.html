统一交易流程

模拟与实盘只在成交端分流

  1. 同一实时输入只使用当时已经到达的数据。
  2. 同一策略判断模拟和实盘执行完全相同的入场与退出规则。
  3. 不同成交端模拟按公开市场价格记账；实盘向 Solana 主网签名发送。
  4. 钱包单策略每个钱包独立启停，失败时只暂停该钱包。
